# docker-compose
- 用于定义和管理`多容器Docker应用`的`工具`
    - 本质还是用docker引擎
- 用yaml文件配置, 然后使用单个命令创建并启动所有服务
1. 本身还是docker run的命令
    1. services, 定义一个数组存放多个容器
    2. image
    3. container_name, --name
    4. environment, -e
    5. vloume, -v
    6. ports, -p
    7. networks, --networks
    8. depends_on, compose专用
    9. restart, --restart
2. 常用命令
# 安装docker-compose
- 使用docker-compose V2
```
docker-compose version   
```
