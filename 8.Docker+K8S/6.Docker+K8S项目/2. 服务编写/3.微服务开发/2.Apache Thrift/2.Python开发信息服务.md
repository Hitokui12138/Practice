```thrift
namespace java com.imooc.thrift.message

service MessageService{
  bool sendMobileMessage(1:string mobile, 2:string message);
  bool sendEmailMessage(1:string email, 2:string message);

```

3. 执行后生成文件夹
    1. 找到生成的接口
        - message
            - api
                - MessageService.py
    2. 建一个实现类(创建一个服务)来实现两个接口
        - MessageServiceHandler
        ```py
        class MessageServiceHandler:
            def sendMobileMessage(self, mobile, message):
                print("sendMobileMessage, mobile: " + mobile + ", message: " + message)
                return True

            def sendEmailMessage(self, email, message):
                print("sendEmailMessage, email: " + email + ", message: " + message)
                messageObj = MIMEText(message, "plain", "utf-8")
                messageObj['From'] = sender
                messageObj['To'] = email
                messageObj['Subject'] = Header('慕课网邮件', 'utf-8')
                try:
                    smtpObj = smtplib.SMTP('smtp.163.com')
                    smtpObj.login(sender, authCode)
                    smtpObj.sendmail(sender, [email], messageObj.as_string())
                    print("sendEmailMessage success")
                    return True
                except smtplib.SMTPException as ex:
                    print("sendEmailMessage fail")
                    print(ex)
                    return False
        ```
    3. 目前的问题在于, Thrift不知道有这个实现类, 因此要写一个主函数来与thrift对接
        1. 作为一个服务, 应该监听一个端口
            - Thrift提供
        ```py
        if __name__ == '__main__':
            # 用于封装handler, 这个构造方法是自动生成的
            handler = MessageServiceHandler()
            processor = MessageService.Processor(handler)  

            # 1. 开启一个ServerSocket, 监听本机一个端口9090 , 只绑定到127.0.0.1，可能无法被所有客户端访问,绑定到所有接口（0.0.0.0）
            transport = TSocket.TServerSocket("0.0.0.0", 9090)
            # 2. 传输方式 按照帧传输
            tfactory = TTransport.TFramedTransportFactory()
            # 3. 传输协议 二进制传输
            pfactory = TBinaryProtocol.TBinaryProtocolFactory()

            # 4. 准备工作完成后创建server
            server = TServer.TSimpleServer(processor,transport, tfactory, pfactory)
            print("python thrift server 开始")
            server.serve()
            print("python thrift server 结束")
        ```
    4. 验证9090有没有启动
        - netstat -an | grep 9090
