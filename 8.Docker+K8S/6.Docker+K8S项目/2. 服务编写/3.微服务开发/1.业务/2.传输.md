#  传输层概览
1. Thrift的通讯分为三个层次
    - 应用层 -> 协议层 -> 传输层
# Socket传输
- 就像是普通电话线
- Socket 传输是最基础的 TCP 网络通信方式。适用于简单的客户端-服务器通信, 不需要高性能的场景(比如测试开发)
1. 优点
    1. 基于 TCP：可靠的、面向连接的字节流
    2. 阻塞 I/O：同步操作，一个连接一个线程
    3. 简单直接：适合小规模、低并发场景
    4. 无缓冲区管理：每次读写可能产生多次系统调用
# 传输方式 (传输层)
1. 帧传输（TFramedTransport）
    - 帧传输在数据前面添加一个长度字段，形成一个"帧"。
    - [4字节长度][数据内容]
    - 添加消息边界，相当于"快递包裹"
    2. 帧传输的特点
        1. 消息边界清晰：通过长度字段知道完整消息大小
            - 支持异步：适合非阻塞 I/O
        2. 必须配对使用：客户端和服务端必须同时使用帧传输
2. 缓冲传输（TBufferedTransport）
    - 写入时：应用数据 → 缓冲区 → 批量写入网络
    - 读取时：网络数据 → 缓冲区 → 分批给应用

# 协议层
- 定义数据如何编码。
1. 二进制编码, TBinaryProtocol
    - 二进制编码协议，高效但不可读
2. 更紧凑的二进制编码, TCompactProtocol
3. JSON 文本格式, TJSONProtocol
    - JSON 编码协议，可读但效率低
4. 简化的 JSON, TSimpleJSONProtocol
