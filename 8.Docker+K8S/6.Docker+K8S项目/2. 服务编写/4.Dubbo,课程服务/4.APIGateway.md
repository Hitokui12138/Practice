# SpringCloud Zuul
- 使用Zuul实现路由功能
- 将外部请求转发给两个EdgeService
- 方案A（推荐，面向未来）：放弃 Zuul，升级到完整的、版本兼容的 Spring Cloud 体系，并使用 Spring Cloud Gateway 作为网关。这是最可持续的方案。
# 配置
1. 依赖
    ```xml
        <dependency>
            <groupId>org.springframework.cloud</groupId>
            <artifactId>spring-cloud-starter-zuul</artifactId>
            <version>1.1.5.RELEASE</version>
        </dependency>
    ```
2. 在启动类里加上 `@EnableZuulProxy` ,使用Zuul的功能
3. 在配置文件中记载转发规则
    ```properties
    # 端口转发?
    server.port=8080

    #course转发给8081
    zuul.routes.course.path=/course/**
    zuul.routes.course.url=http://localhost:8081

    #user转发给8082
    zuul.routes.user.path=/user/**
    zuul.routes.user.url=http://localhost:8082
    ```

# SpringCloudGateway
- 遇到版本问题, 把Zuul换成SpringCloudGateway
1. 不要保留pring-boot-starter-web
Spring Cloud Gateway 基于 Spring WebFlux，这是一个异步、非阻塞、反应式的Web框架。

Spring MVC（由 spring-boot-starter-web 引入）是传统的同步、阻塞式Web框架。
