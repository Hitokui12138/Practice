2. 原因可能是连不上zookeeper
  - ZooKeeper（地址 172.20.10.13:9090）
  - 这是一个典型的服务依赖未启动的问题, 应用依赖 ZooKeeper，但 ZooKeeper 服务没有启动或不可达
3. 查询zookeeper的详细信息(地址和端口号)
  - `docker ps | grep -i zookeeper`
  - `docker inspect zookeeper`
    - 可以看到 "IPAddress": "172.17.0.4", 
  - `docker port zookeeper`
    - 发现只有2181, 没有9090
4. 查看所有容器的连接方式
  - `docker network ls`
5. 最终发现原因在于properties文件中写的不对
  - 修改前: dubbo.registry.address=zookeeper://${zookeeper.address}
  - dubbo.registry.address=zookeeper://${zookeeper.address}:2181
6. 其他
  1. Gateway（网关）和IPAddress（容器IP）。应该改为Redis容器的IP地址（172.17.0.2）或者使用容器名称（如果你将Redis容器连接到同一个网络，并使用容器名称）。
