# 运行一个官方提供的事例kubernetes-bootcamp
1. 创建一个deployment, 从官网镜像拉取
    - `kubectl create deployment kubernetes-bootcamp --image=jocatalin/kubernetes-bootcamp:v1 --port=8080`
        - 在创建deployment之后立即会生成一个pod
    - `kubectl get deployments`
2. 在8080端口运行
    - `kubectl run kubernetes-bootcamp --image=gcr.io/google-samples/kubernetes-bootcamp:v1 --port=8080`

# 报错后的debug方法
```sh
# 1. 查看Pod的详细状态和最近事件
kubectl describe pod kubernetes-bootcamp-7fb78bdcf8-zwz87

# 2. 查看Pod的日志（即使容器没启动，也可能有错误输出）
kubectl logs kubernetes-bootcamp-7fb78bdcf8-zwz87
```
