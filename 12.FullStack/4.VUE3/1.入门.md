# 使用Vue进行开发
1. 其他开发模式
    1. 使用CLI创建应用程序
        - vue2用的多,现在已经停止维护
    2. 引入vue.js核心库（只能用于简单页面）
2. 组件说明： 
    0. Nginx, 类似于tomcat
    1. **Node.js**：运行环境（JS 脱离浏览器跑起来的基础）
    2. **npm**：包管理器（下载、管理第三方代码工具）
    3. **Vite**：前端构建工具（开发、打包 Vue/React 项目）
2. 安装NodeJS 18.0以上版本
    1. 下载LTS长期支持版本
        - node -v
    2. 安装 Node.js 之后，自动附带 npm。
        - npm -v
    3. npm 可能需要配置中央仓库
        - npm config get registry https://....
        - npm config list
3. Vite， 类似于maven的作用， 打包组件
    1. 无需手动安装，直接执行 `npm create vite@latest`
        - 使用TypeScript
        - 然后就能创建一个标准的项目
    2. 旧版可能需要手动下载依赖
        - `npm install`
            - 依赖放在/node_moodules里面
        - `npm run dev`， 启动
4. 在vsCode中安装 VUE-Official 插件

# 项目文件夹介绍
1. node_moodules， 依赖文件
2. public， 一般用来装静态文件，图片，视频
3. src， 源码根目录
    1. /src/main.ts,引入vue的`createApp`, 创建应用`App.vue`，然后绑定到`#app`
    2. App.vue, 一个标准的VUE文件包括三部分
        1. script， 脚本
        2. template， 模版， 控制显示
        3. style， 样式
4. index.html, 整个应用访问的入口
    - 引入`/src/main.ts`， 提供`#app`
5. package.json, 就是pom文件
    1. devDependences
    2. scripts， 项目启动时的脚本
        - `npm run dev`这个dev对应的就是里面的脚本
        - build， 可以把项目打包成可以在服务器上运行的
