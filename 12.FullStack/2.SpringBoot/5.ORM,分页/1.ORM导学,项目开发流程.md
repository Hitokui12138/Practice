# ORM
1. 和面向对象一样是一种思想
2. 数据库是什么
    1. 用来存储数据,数据库,数据表,字段
3. ORM
    - `用面向对象的方式`处理数据库
        - 依赖,也是面向对象的一种方式
    - Object Relation Mapping, 对象关系映射
    - 希望不要直接操作数据表和字段, 而是操作类对象,以及其下面的属性和成员变量
4. 关于ORM的Model自动生成数据表
    - 一个Model(类), 表示一张表
    - 但是在大的项目里还是推荐使用数据库工具或者DDL创建数据库
        - ORM强调的是操作数据库, 而不是生成数据库
# 数据库工具(Navicat)ER图
- 点击“模型”,进入ER图界面
1. 两个表没有连接在一起?
    - 只有存在物理外键时,ER图中两个表才会连起来 
2. 再次强调不要把它们当作数据表,而是应该当作类来设计
    - 外键 -> 两个类之间的依赖
# 开发大型项目的顺序
1. 优先开发`CMS`,主要给工作人员使用,用于修改数据
    - 正规的大型项目中,应该通过CMS与数据库交互
    - To O(Operator),运营
    1. 传统的CMS PHP, 不是前后分离的, 都是由服务器渲染的(小程序也是)
        - 但现在应当前后分离
        - 比较知名的CMS框架: WordPress(基于PHP的内容管理框架)
    2. 先开发前段还是后端?
        1. 建议先后端,因为后端可以提供数据,造数据太难了
2. 第二阶段开发C端应用程序
