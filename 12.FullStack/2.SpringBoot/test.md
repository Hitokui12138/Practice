● **涉及技术**：Spring Boot，Spring Batch，Dubbo（RPC），RocketMQ（事件/定时/异步解耦），Docker / Docker-Compose，AWS（S3 等），Zookeeper（Dubbo 注册中心），分布式任务与批处理。
● **负责工作**：

1. **核心业务 API 与服务化建设（管理端 + 加盟商端）**

   1. 基于 Spring Boot + Dubbo 开发加盟商管理服务，提供入驻申请、信息审核、合约查询等 RPC 接口，支撑内部管理后台的统一调用与业务复用。
   2. 设计并实现加盟商侧 REST API（收益分成申请、结算明细查询、收益一览等），复杂统计类查询通过 Dubbo 调用独立数据服务完成，保障接口职责清晰与能力复用。
   3. 针对“收益一览/结算明细”等高频页面接口进行分页统计与查询性能优化（复杂筛选、聚合统计、分页稳定性），提升接口响应与可用性。

   1. 主导基于 Spring Batch 的分布式批处理模块设计与实现，日终精算任务由 RocketMQ 定时消息触发，形成稳定可控的批处理调度机制。
   2. 设计并落地多支付渠道（nanaco、WAON、交通系等）的差异化对账与日报生成引擎：自动加工海量交易数据，生成精准的收益核算 CSV（日/月报）并满足对账口径一致性。
   3. 批处理过程中通过 Dubbo 远程调用交易服务与账户服务获取原始交易数据，完成清洗、汇总、对账与结算计算，并在任务完成后发送“报表就绪”事件，实现批处理链路异步化与可扩展。
   4. 对批处理任务的稳定性进行工程化保障：围绕重试、幂等、失败回滚/补偿、任务状态可追踪等机制提升批任务可靠性与可运维性。

3. **云平台部署与分布式联调支撑（AWS + Docker + 中间件）**

   1. 使用 Docker-Compose 搭建本地分布式集成测试环境（Dubbo 服务、RocketMQ NameServer/Broker、业务应用等），提升开发联调效率与问题复现能力。
   2. 负责 AWS 生产环境部署与配置，完成 Dubbo 注册中心（Zookeeper）与 RocketMQ 集群接入及参数调优，保障服务治理与消息链路稳定运行。
