# 多例模式 @Scope("prototype")
## 验证SpringBoot的单例模式
```java
@RestController
@RequstMapping("/test")
public class TestController(){
    @Autowired
    private Test test1;
    @Autowired
    private Test test2;
    @GetMapping("")
    public void getDetail(){
        sout(this.test1);
        sout(this.test2);
    }
}
```
1. 多次访问这个api,可以发现每次打印出来的`this.test`的号码都是相同的
    - 说明每次调用的test都是同一个对象,且test1始终和test2相同

## 开启多例模式
```java
@Component
@Scope("prototype")
public class Test{
    //...
}
```
- 这样test1和test2值就不相同了, 但是每次调用, test1还是test1, test2还是test2, 我们希望每次调用都能创建一个新对象来应对不同的订单

## 方法1: 不使用成员变量注入, 而是使用参数注入
```java
@RestController
@RequstMapping("/test")
public class TestController(){
    @Autowired
    private Test test;

    @GetMapping("")
    public void getDetail(@Autowired Test test){
        sout(this.test);
    }
}
```

## 方法2: 使用对象工厂
- 每次调用都是不同的对象
```java
@RestController
@RequstMapping("/test")
public class TestController(){
    @Autowired
    private ObjectFactory<Test> test;

    @GetMapping("")
    public void getDetail(){
        sout(this.test.getObject);
    }
}
```

## 方法3: 动态代理
```java
@Component
@Scope("prototype", proxyMode= ScopedProxyMode.TARGET_CLASS)
public class Test{
    //...
}
```
- 如果使用调试模式, 会发现test是由`SpringCGLib`代理的
    - EnhancerBySpringCGLib
