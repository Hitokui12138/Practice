# 下订单
## Order表
1. OrderNumber 不能重复, 需要自己生成
2. 总价, sku总件数
    1. 最终价格, 折扣后的实际金额
3. snap 快照
    1. snap_img,
    2. snap_title, 
    3. snap_items, json sku列表
        - 也可以做成另一张表, 但考虑这个不会变, 因此做成json格式
    4. snap_address,json 用户下单的地址
4. 订单的状态
## 前端提交的Price是不可信的
- 前端的价格仅仅是显示给用户参考
- 后段需要对价格进行校验
## 订单需要校验哪些信息?
1. 商品是否有货
2. 商品最大购买数量,限购问题
3. 原价, 优惠券和最终价格
4. 用户是否拥有该优惠券, 优惠券是否过期
