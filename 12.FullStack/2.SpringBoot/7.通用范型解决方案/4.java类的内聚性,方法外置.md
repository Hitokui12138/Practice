## 
1. 前面做的MapAndJson和ListAndJson解决了json映射的问题
2. 问题:
    1. 失去了`类的优势`
        - List和Map让类失去了业务意义, 现在只能调用List和Map的方法了
        - 之前是定义了一个spec类,如果业务拓展, 可以在里面加上新的定义,新的业务方法
        - 如果一个类只能保存数据,无法处理方法,则方法必须外置(即不定义在这个类里面)
            - `能内置的方法不应该外置`
    2. 前端的两种组织数据的格式
        1. {key : value}
        2. class
3. 现在的Model相当于POJO
    - 专门用来存储数据的,没有行为方法
    - 但完全不在Model里面写方法会造成外部代码冗余
    - 因此还是应当看作是一个业务模型(类似于service那样), 应该有一些内置的业务方法
4. 有的项目会在Model上面加一层写业务方法, Model里面完全不写
    - 老师认为这个很死板

## 解决类的能力失去这个问题的一种方案
1. 强类型
    - 直接定义`List<Spec> specs`,这样就能在Spec类里定义方法
        - 缺点是之后每个类似的字段都需要单独的`SpecAndJson`这样的处理
    - 既想要强类型的特性, 又想共通处理
        - 多种类型->范型
2. 注意这个Object, 因此想办法用范型替换这个
    - `public class ListAndJson implements AttributeConverter<List<Object>, String> {}`
    - 但Java的范型有缺陷,不能直接改成T
3. 序列化
    - mapper.writeValueAsString(stringObjectMap);
    - 不需要知道类型,因此处理起来很简单
4. 反序列化
    - mapper.readValue(s, HashMap.class);//需要元类
        - 这里不能直接改成`T.class`, Java的范型不能直接获取元类
    - 这个HashMap.class可以参考之前的PagingDozer,用参数传进来
5. Java的范型是编译范型,如果要把Object改成T的话, 在调用ListAndJson时,应该把T的类型传进去
    - 但是Converter的使用方式是这样
    ```java
    @Convert(converter = ListAndJson.class)
    private List<Object> specs;
    ```
## 强类型+范型 仅把Spec当作范型, `List<T>`
- 还是用SetterGetter来解决(不要碰@Convert)
1. 范型的选择
    1. 把`List<Spec>`整体当作范型T
    2. 仅把Spec当作范型, `List<T>`
2. 仅把Spec当作范型, `List<T>`
    - 有个问题是`readValue(s, List<Spec>.class)`不符合java语法
    1. 引入一个Jackson的抽象类`TypeReference`
        - readValue(String, TypeReference<T> ref),重载方法
```java
@Component //因为有@Autowired, 又没有继承特定类, 因此需要手动加入容器
public class GenericAndJson {
    //@Autowired 不能注入Static
    private static ObjectMapper mapper;

    /**
     * 通过方法来桥接依赖注入和Static变量
     * 这样,在容器运行时, 就会把ObjectMapper注入到setMapper()这个方法里面
     * @param mapper
     */
    @Autowired
    public void setMapper(ObjectMapper mapper){
        GenericAndJson.mapper = mapper;
    }

    /**
     * 序列化
     * 静态方法如何依赖注入? 依赖注入静态成员变量?
     * 这是不可能的, 依赖注入肯定是有一个实例化的过程
     * @return
     * @param <T>
     */
    public static <T> String objectToJson(T o){
        try {
            return GenericAndJson.mapper.writeValueAsString(o);
        } catch (JsonProcessingException e) {
            e.printStackTrace();
            throw new ServerErrorException(9999);
        }
    }

    /**
     * 单一Json处理
     * 如何传入范型T的原类?
     * 模仿PagingDozer, 传入 Class<T> tClass
     * 另外, 在使用时, ( List<Spec>.class )也是错误的语法
     * @param s
     * @return
     */
//    public <T> T jsonToObject(String s, Class<T> tClass) {
//        try{
//            if (null == s){
//                return null;
//            }
//            T o = GenericAndJson.mapper.readValue(s ,tClass);
//            return o;
//        } catch(Exception e){
//            e.printStackTrace();
//            throw new ServerErrorException(9999);
//        }
//    }

    /**
     * 在使用时,会遇到List<Spec>.class这样的问题, 不符合Java语法
     * 使用Jackson的一个抽象类TypeReference
     * 不管是单体还是List都可以用这个方法
     * @param s
     * @param tr
     * @return
     * @param <T>
     */
    public static <T> T jsonToList(String s, TypeReference<T> tr){
        try{
            if (null == s){
                return null;
            }
            T list = GenericAndJson.mapper.readValue(s ,tr);
            return list;
        } catch(Exception e){
            e.printStackTrace();
            throw new ServerErrorException(9999);
        }
    }
}

//调用
    /**
     * 使用GenericAndJson
     */
    private String specs;
    public List<Spec> getSpecs() {
        if(this.specs == null){
            return Collections.emptyList();
        }
        return GenericAndJson.jsonToList(this.specs,
                new TypeReference<List <Spec>>(){}); //新建抽象类->匿名类,加上花括号
    }
    public void setSpecs(List<Spec> specs) {
        if(specs.isEmpty()){
            return;
        }
        this.specs = GenericAndJson.objectToJson(specs);
    }
```

    /**
     * 演示将`List<Spec>`整体看作T的情况
     * 好处是TypeReference的定义可以放在工具类里面
     */
    public static <T> List<T> jsonToList(String s){
        try{
            if (null == s){
                return null;
            }
            List<T> list = GenericAndJson.mapper.readValue(s,
                    new TypeReference<List<T>>() {});
            return list;
        } catch(Exception e){
            e.printStackTrace();
            throw new ServerErrorException(9999);
        }
    }
