# JSR303
## 问题
```java
@GetMapping("/by/category/{id}")
public PagingDozer<Spu, SpuSimplifyVO> getByCategoryId(
        @PathVariable
        @Positive(message = "必须为正数")
        Long id
    ){...}
```
- 像是这里的@Positive的Message无法使用配置文件来进行管理
- SpringBoot提供了一套专门管理JSR303标准的消息的方法
## 创建 ValidationMessages.properties
1. 文件名是固定的
    ```properties
    # 专门用来设置JSR303标准的Message
    id.positive = id必须是正整数
    id.other = {max}{min}XXX
    ```
2. 使用的地点
    - `@Positive(message = "{id.positive}")Long id`
3. 效果
    - "message": "getById.id: id必须是正整数"
4. 去掉前缀
    - 可以想到这里异常处理会经过` @ExceptionHandler(ConstraintViolationException.class)`
    - 在里面进行处理
