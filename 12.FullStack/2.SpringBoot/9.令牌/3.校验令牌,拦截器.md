## 校验JWT令牌
```java
    /**
     * 解析并获取JWT里面的Claims
     * 在这个方法中, 自己尝试返回Optional实例
     * @param token
     * @return
     */
    public Optional<Map<String, Claim>> getClaims(String token){
        //生成时有指定算法(钥匙), 那么解析时也需要这个钥匙
        Algorithm algorithm = Algorithm.HMAC256(JwtToken.jwtKey);
        // 专门用来解析Token的核心类
        JWTVerifier jwtVerifier = JWT.require(algorithm).build();
        //校验异常可能会抛出校验失败的异常
        DecodedJWT decodedJWT;
        try{
            decodedJWT = jwtVerifier.verify(token);
        }catch (JWTVerificationException e){ //文档里有写
            // 参数校验之类的由用户引起的异常不必计入日志
            // 也可以在这里分别判断令牌无效或者令牌过期
            //return null; 返回null有空指针风险
            return Optional.empty();
        }
        return Optional.of(decodedJWT.getClaims());
    }
```
## 拦截用户请求
- 是一种AOP的应用,类似于ControllerAdvice
- 建一个类, 拦截所有的HTTP请求
    - filter, intercepter, aop(在切面上实现某些功能)
1. `filter`是基于`servlet`的, 而`intercepter`和`aop`是基于`spring`的
    1. servlet
        - servlet是一套标准规范(就像是接口)
        - 接口不能接收HTTP请求, 只有`实现servlet接口的容器`(比如tomcat)才能接受HTTP亲故
    2. python是基于wsgi规范, uwsgi是实现该规范的容器之一
    3. KoA里面的中间件, 就是intercepter
2. 如果同时做了这三种机制的类, 执行顺序是?
    1. request -> 服务器 -> filter -> intercepter -> aop -> controller
        - 因为filter是底层的
    2. response -> aop -> intercepter -> filter -> 客户端
        - 刚好反过来, `洋葱模型`
3. spring的功能更多一些, 所以尽量不要使用filter
4. aop的粒度更小, 比如对一个类的一个方法去做aop
    - @BeforeEach, @AfterEach
5. 对于这个需求, 建议使用intercepter
    - 还有流量保护(防Dos)等等功能可以使用intercepter来实现 

6. 分析拦截器逻辑,在写方法之前先捋清思路
    1. 获取请求的token
    2. 验证token
    3. 权限相关
        1. 读取scope
        2. 读取访问的API的@ScopeLevel的值
        3. 比较这两个值
```java
public class PermissionInterceptor extends HandlerInterceptorAdapter {
    /**
     * 1. 进入Controller之前
     * 这里的返回值boolean, 当为true时表示这个是公共API, 无需对比权限
     * 想拒绝访问则抛出异常
     */
    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) throws Exception {
        // 1. 取得API的ScopeLevel
        Optional<ScopeLevel> scopeLevel = this.getScopeLevel(handler);
        if (!scopeLevel.isPresent()){
            return true;
        }
        // 2. 获取前端的令牌
        /*
        前端的Header里面是一个个键值对
        约定俗成token要放在“Authorization”这个键下面
        格式: Authorization:Bearer <token>
         */
        String bearerToken = request.getHeader("Authorization");
        if(StringUtils.isEmpty(bearerToken)){
            throw new UnAuthenticatedException(10004);
        }
        // 3. JWT的标准 `Authorization:Bearer <token>`
        if(bearerToken.startsWith("Bearer")){
            throw new UnAuthenticatedException(10004);
        }
        //4. 提取JWT令牌, 如果有加密则还需要解密, 比较过期时间等等
        Optional<Map<String, Claim>> optionalMap = JwtToken.getClaims(bearerToken);
        Map<String, Claim> map = optionalMap.orElseThrow(
                () -> new UnAuthenticatedException(10004)
        );
        boolean isValid = this.hasPermission(scopeLevel.get(), map);

        return isValid;
    }

    //2. 在覆盖页面之前,提供一个修改ModelAndView的机会
    @Override
    public void postHandle(HttpServletRequest request, HttpServletResponse response, Object handler, ModelAndView modelAndView) throws Exception {
        super.postHandle(request, response, handler, modelAndView);
    }

    //3. 常用于最后清理资源
    @Override
    public void afterCompletion(HttpServletRequest request, HttpServletResponse response, Object handler, Exception ex) throws Exception {
        super.afterCompletion(request, response, handler, ex);
    }

    /**
     * 返回值是注解?
     * 参数参考上面几个方法
     * 获取注解值的方法
     */
    private Optional<ScopeLevel> getScopeLevel(Object handler){
        if(handler instanceof HandlerMethod){
            HandlerMethod handlerMethod = (HandlerMethod) handler;
            //获取Scope注解
            ScopeLevel scopeLevel = handlerMethod.getMethod()
                    .getAnnotation(ScopeLevel.class);
            return Optional.of(scopeLevel);
        }
        return Optional.empty();
    }

    /**
     *
     */
    private boolean hasPermission(ScopeLevel scopeLevel, Map<String, Claim> map){
        Integer apiLevel = scopeLevel.value();
        Integer userScope = map.get("scope").asInt();//Claim自带一些转型方法
        if(apiLevel > userScope){ //相同时则允许访问
            throw new ForbiddenException(10005);
        }
        return true;
    }
```

## 注册Interceptor
- 类虽然写好了,但还不能用, 需要注册
```java
@Component
public class InterceptorConfiguration implements WebMvcConfigurer {
    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(new PermissionInterceptor());
    }
}
```
