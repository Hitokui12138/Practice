## CategoryController
1. 分类页面的一次加载所有分类的API
2. 首页六宫格的那个API
## 重点
1. Category和Coupon是双向多对多关系
    1. 双方都有对方的导航属性, 如果序列化,会无限循环下去
    2. 本身分类页面的API不需要Coupon相关信息,应该去掉

## Service
- 分别取得根节点和其他节点的数据
```java
/**
 * 如何返回两个结果?
 * 组合成一个结果
 * 1. HashMap
 * 2. 定义Pair<T, K>
 */
public Map<Integer, List<Category>> getAll(){
    //根节点
    List<Category> roots =categoryRepositoryfindAllByIsRootOrderByIndexAsc(true);
    //二级节点
    List<Category> subs =categoryRepositoryfindAllByIsRootOrderByIndexAsc(false);
    Map<Integer, List<Category>> categories= new HashMap<>();
    categories.put(1, roots);
    categories.put(2, subs);
    return categories;
}
```

## Controller
- 如果直接给前端返回categories, 会出现循环序列化问题
    - 也就是说return之前是安全的
- 新建一个VO专门用来修改categories
### CategoriesAllVO
```java
/**
 * VO的意义:
 * 前端想要的数据结构和数据库的数据结构不同时
 * 定义前端需求于VO, 然后把数据库的值Mapping进去
 * 然后向前端返回VO
 *
 * 一些不想写在Controller里的数据转换逻辑也可以写在
 */
@Getter //重要! 序列化必须有Getter,Setter
@Setter
public class CategoriesAllVO {
    private List<CategoryPureVo> roots;
    private List<CategoryPureVo> subs;

    /**
     * Category和Coupon有多对多的关系,这回造成两个问题
     * 1. 前端在获取页面信息时不需要Coupon
     * 2. 双向多对多关系可能造成循环序列化,从而内存泄露
     *      2.1 配置双向关系后,要有选择地序列化,只序列化一遍 @JsonIgnore
     *      2.2 创建Category的VO来去掉不要的导航属性和字段
     */
    public CategoriesAllVO(Map<Integer, List<Category>> map){
//        List<Category> roots = map.get(1);
//        roots.foreach(r ->{ //Consumer
//            CategoryPureVo vo = new CategoryPureVo(r);
//            this.roots.add(vo);
//                }
//        )

        // 用Stream解决这个
        this.roots = map.get(1).stream()
                .map(r -> { //把每一个Category map成 VO
                    return new CategoryPureVo(r);
                })
                .collect(Collectors.toList()); //最终结果要List, 因此collect
        //把每一个Category map成 VO
        this.subs = map.get(2).stream()
                .map(CategoryPureVo::new)
                .collect(Collectors.toList()); //最终结果要List, 因此collect
    }
}
```
### CategoryPureVo
- 具体的精简方法写这里
- 完整的RESTFul返回的结果太大了, 内部API尽量只返回需要的信息
- 之所以新写一个类是为了使用BeanUtils的方法
```java
@Getter
@Setter
public class CategoryPureVo {

    private Long id;

    private String name;

    //private String description;

    private Boolean isRoot;

    private String img;

    private Long parentId;

    private Long index;

    // Coupon相关的也去掉
    public CategoryPureVo(Category category){
        BeanUtils.copyProperties(category, this);
    }
}
```
