## 购买的课程和售出的课程
### 1. 购买的课程
- 对 POST /api/bookings/my-purchased-courses 增加这 4 个场景能力。
不传，ONGOING，GROUP，ENDED
1. scene = ALL/null：按游标返回 pendingPaymentList（支付状态 PENDING）+ normalPage。
    scene=ALL/null 时分两段查询：
    normalPage：游标分页查询，状态集改为
    PAID / PROCESSING / PENDING_REVIEW / COMPLETED / CANCELLED / REFUNDED（排除 PENDING）
    pendingAll：仅在 orderId == null（第一页）额外查询全部 PENDING（同样带 keyword 过滤）
    列表合并规则：
    首页：finalList = pendingAll + normalPage.list
    非首页：finalList = normalPage.list
2. scene = ONGOING： 进行中：PROCESSING。
3. scene = GROUP： 拼团相关：bizType = GROUP。
4. scene = ENDED： 已结束：COMPLETED + REFUNDED + CANCELLED+ PENDING_REVIEW。
### 2. 售出的课程
- /api/bookings/my-sold-courses

    - 保持历史口径：ALL 仍只查已成交相关（不含 PENDING/CANCELLED）
2. scene = ONGOING： 进行中：PROCESSING 。
3. scene = GROUP： 拼团相关：bizType = GROUP。
4. scene = ENDED： 已结束：COMPLETED + REFUNDED + CANCELLED + PENDING_REVIEW
