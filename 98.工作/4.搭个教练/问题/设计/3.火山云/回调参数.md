# veImageX 智能审核回调参数说明（整理版）

## 图片回调内容
您在智能审核开启回调后，在图片审核结束后 veImageX 会将审核结果以 json 形式回调至您的回调地址。您可以通过回调内容，进行后续的文件处理操作。

| 参数名 | 类型 | 含义 |
|--------|------|------|
| Id | String | 审核任务中图片对应 EntryID |
| Image | String | 图片资源 URI 或 URL。取决于创建任务传入的资源地址 |
| Status | String | 审核状态：<br>Success：成功<br>Fail：失败 |
| AuditImageType | String | 审核后图片类型：<br>normal：正常<br>frozen：冻结图片<br>problem：问题图片<br>fail：审核失败 |
| AuditSuggestion | String | 审核建议：<br>nopass：建议不通过<br>recheck：建议复审 |
| InvolveDimension | Array of String | 审核后图片涉及的违规 tag |
| SubLabel | Array of String | 详见图片标签 |

---

## 音频回调内容
您在智能审核开启回调后，在音频审核结束后 veImageX 会将审核结果以 json 形式回调至您的回调地址。您可以通过回调内容，进行后续的文件处理操作。

| 参数名 | 类型 | 含义 |
|--------|------|------|
| TaskId | String | 审核任务 ID |
| Id | String | 审核任务中音频对应 EntryID |
| Url | String | 资源 URI 或 URL。取决于创建任务传入的资源地址 |
| AuditAudioType | String | 审核后音频类型：<br>normal：正常<br>frozen：冻结音频<br>problem：问题音频<br>fail：审核失败 |
| AuditAudioSuggestion | String | 审核建议：<br>nopass：建议不通过<br>recheck：建议复审 |
| AuditAudioDetails | AuditAudioDetails | 音频审核结果详情（正常音频不返回） |
| InvolveDimension | Array of String | 审核后音频涉及的违规 tag |
| SubLabel | Array of String | 详见音频标签 |
| Status | String | 审核状态：<br>Success：成功<br>Fail：失败 |

### AuditAudioDetails
| 参数名 | 类型 | 含义 |
|--------|------|------|
| StartTime | Int | 切片开始时间，单位：秒 |
| EndTime | Int | 切片结束时间，单位：秒 |
| AudioText | String | 音频 ASR 转换后的文本 |
| SliceId | String | 音频切片的唯一 ID |
| Decision | String | 当前音频切片处置建议：PASS / REVIEW / BLOCK |
| FinalSubLabel | String | 风险值最高的一级标签 |
| DecisionSubLabel | String | 风险值最高的二级标签（对应 FinalSubLabel） |

---

## 视频回调内容
您在智能审核开启回调后，在视频审核结束后 veImageX 会将审核结果以 json 形式回调至您的回调地址。您可以通过回调内容，进行后续的文件处理操作。

| 参数名 | 类型 | 含义 |
|--------|------|------|
| TaskId | String | 审核任务 ID |
| Id | String | 审核任务中视频对应 EntryID |
| Url | String | 资源 URI 或 URL。取决于创建任务传入的资源地址 |
| AuditAudioType | String | 审核后视频声音类型：<br>normal：正常<br>frozen：冻结<br>problem：问题<br>fail：审核失败 |
| AuditVideoType | String | 审核后视频画面类型：<br>normal：正常<br>frozen：冻结<br>problem：问题<br>fail：审核失败 |
| AuditAudioSuggestion | String | 视频声音审核建议：<br>nopass：建议不通过<br>recheck：建议复审 |
| AuditVideoSuggestion | String | 视频画面审核建议：<br>nopass：建议不通过<br>recheck：建议复审 |
| AuditAudioDetails | Object of AuditAudioDetails | 视频声音审核结果详情 |
| AuditVideoDetails | Object of AuditVideoDetails | 视频画面审核结果详情 |
| InvolveDimension | Array of String | 审核后视频涉及的违规 tag |
| SubLabel | Array of String | 详见视频标签 |
| Status | String | 审核状态：<br>Success：成功<br>Fail：失败 |

### AuditAudioDetails（视频声音）
| 参数名 | 类型 | 含义 |
|--------|------|------|
| StartTime | Int | 切片开始时间，单位：秒 |
| EndTime | Int | 切片结束时间，单位：秒 |
| AudioText | String | 视频音频 ASR 转换后的文本 |
| SliceId | String | 视频音频切片唯一 ID |
| Decision | String | 处置建议：PASS / REVIEW / BLOCK |
| FinalSubLabel | String | 风险值最高的一级标签 |
| DecisionSubLabel | String | 风险值最高的二级标签 |

### AuditVideoDetails（视频画面）
| 参数名 | 类型 | 含义 |
|--------|------|------|
| Offset | float64 | 视频截帧距离片头的时间戳，单位：秒 |
| SliceId | string | 截帧图片唯一 ID |
| Decision | String | 截帧处置建议：PASS / REVIEW / BLOCK |
| Text | String | 截帧中识别出的文本内容 |
| FinalSubLabel | String | 风险值最高的一级标签 |
| DecisionSubLabel | String | 风险值最高的二级标签 |
