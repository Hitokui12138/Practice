# 拼课功能  
1. 用户下单时选择成团人数， 然后计算单人价格， 用户支付单人价格后成为团主，然后开始计时48小时
2. 用户使用分享功能
    1. 公开链接，任何已注册的用户都可以参加拼团
    2. 私人链接，要求该已注册的用户和团主是 好友/互关 的关系
3. 在订单有效期间，其他人如果想参加，则支付单人价格后加入拼团
4. 若计时结束后仍未成团， 则自动取消这笔订单， 给每个人自动退款

## 个别团员退款问题
我想再讨论一下 阶段C：已开课后的个体冲突
1. 缺课补课 和 顺延次数 会造成教练额外工作， 如何补偿？
2. 转让名额， 是要拉新人进团吗？感觉逻辑是线上上会很复杂
3. 关于 比例退款， 拼团课本身单价就便宜， 担心会有人注册小号参团后再退款， 如何解决？

你这三个担心非常专业，而且都是真问题。我的建议是：**阶段C先做“可控损失”，不要追求完全灵活**。  

**1) 缺课补课/顺延会增加教练工作，怎么补偿？**

建议把补偿做成“规则化自动结算”，否则运营扛不住：

- **补课补偿金**：每发生一次补课，平台给教练固定补偿（如 `X元/次` 或 `课时费的20%`），从“拼团服务费/风险池”出。
- **顺延补偿金**：顺延导致教练档期被占，按“延后次数”给阶梯补偿（第1次低、第2次高）。
- **触发条件要严**：仅限“团员按规则请假”（提前N小时）才补；临时爽约不补，防滥用。
- **每团上限**：每个团最多补偿 `1~2次`，超出后只给学员缺课处理，不再要求教练额外排补。
- **教练可拒绝窗口**：允许教练在指定时间段拒绝补课请求，平台自动给学员改为退款/积分券方案。

一句话：**补偿标准固定 + 次数封顶 + 触发严格**，教练才愿意长期接拼团。

---

**2) 转让名额是不是拉新人进团？逻辑太复杂怎么办？**

你判断是对的，`MVP` 不建议做自由转让。建议分两期：

- **一期（推荐）**：不做“自由转让给任意人”，只做“平台候补池替补”  
  - 团满后有人退出，按候补顺序自动补位。  
  - 候补用户提前授权支付，补位即扣款，规则简单。
- **二期再做**：团员定向邀请替补（需要风控、支付、权益迁移、聊天关系迁移，复杂很多）。
- **时点限制**：仅允许“首课前”替补，开课后禁转让，避免课次权益切割。

一句话：**先做候补替补，不做自由买卖名额**。

---

**3) 比例退款如何防“小号参团后退款套利”？**

这个风险必须做“资格+成本+风控”三层防护：

- **资格门槛**：仅实名认证+支付实名一致账户可退款；同证件/同支付账户多号参团触发限制。
- **退款门槛**：仅在“规则内冲突”可退（如连续2次无法匹配且有证据），不是想退就退。
- **退款成本**：已开课后退款引入“固定手续费 + 阶梯扣减”（越晚退扣越多），杜绝零成本试错。
- **次数限制**：账号维度月退款次数、设备维度退款率阈值，超限进入人工审核。
- **关联风控**：设备指纹/IP/收款账户/行为轨迹识别关联小号；命中后降权、冻结拼团资格。
- **资金策略**：拼团款先托管，满足退款条件才放行；异常团延迟结算给教练，防薅羊毛后跑单。

一句话：**退款可以有，但不能“低门槛+低成本+高频”**，否则必被薅。
