你这个团购分享功能，建议按「**分享页承载 token**」来做，流程很清晰：

- 发起人创建团后，后端生成 `shareToken`
- 分享出去的是小程序页面路径（带 `shareToken`）
- 被分享人打开后，页面用 `shareToken` 调 `/api/group/detail`
- 页面展示团详情 + 倒计时 + “参团并支付”按钮

**推荐页面路由设计**
- 新建页面：`pages/group/detail/index`
- 打开参数：`pages/group/detail/index?shareToken=20e0...`

**分享实现（核心）**
- 在团详情页实现 `onShareAppMessage`：
  - `title`: `${courseTitle}，还差${remainingCount}人，快来拼团`
  - `path`: `/pages/group/detail/index?shareToken=${shareToken}`
- 可加按钮触发分享：`<button open-type="share">邀请好友参团</button>`

**页面加载逻辑**
- `onLoad(options)` 读取 `options.shareToken`
- 校验 token 非空，否则提示“分享链接无效”
- 请求接口：`GET http://localhost:8000/api/group/detail?shareToken=xxx`
- 渲染字段：
  - 课程名、目标人数、已付人数、剩余人数、单价、状态、成员头像
- 用 `remainSeconds` 做前端倒计时，每秒更新；到 0 自动置为“已过期”

**参团支付建议流程**
- “立即参团”按钮不要直接支付，先调后端“参团下单/预支付”接口
- 后端返回 `payData` 后再 `wx.requestPayment`
- 支付成功后刷新 `/api/group/detail`，更新 `paidMemberCount`/`status`

**你现在要特别注意**
- `localhost:8000` 只适合开发工具本机联调；真机要换成可访问 `https` 域名并配合法域名
- `shareToken` 建议短期有效 + 服务端校验状态（过期/满团/已结束）
- 防重复点击：参团按钮加 `loading + disabled`
