# JPA的懒加载
- 用的时候才加载
```java
@ManyToOne(fetch = FetchType.LAZY)
private User user;
```

1. JPA 懒加载必须在事务内 = 必须在 @Transactional 里面才能用
    - 懒加载需要数据库连接，
    1. 事务 = 数据库连接保持打开
        - 尤其是只读事务容易忘记加
    2. 事务一关，连接就关，懒加载就报错！
2. 而 懒加载 就是：我现在不取，等会儿要用再取
    - 懒加载调用的那一行代码，必须在 @Transactional 范围之内！

## 错误示范
```java
@Service
public class OrderService {
    public Order getOrder(Long id) {
        // 1. 查询订单（只查订单表，user是懒加载，没查）
        Order order = orderRepository.findById(id).get();
        
        // 2. 方法结束 → 数据库连接已经关闭！
        
        return order; // 返回的是只有订单信息的对象
    }
}

// Controller 里调用
Order order = orderService.getOrder(1L);
order.getUser(); // 报错！LazyInitializationException
```

## 正确示范
```java
@Service
public class OrderService {
    //1. 加上事务， 事务不要加在Controller里面
    @Transactional(readOnly = true) //只读事务可以优化查询速度
    //2. 不要返回对象，要返回DTO
    public OrderDTO getOrder(Long id) {
        Order order = orderRepository.findById(id).get();

         // 3.在事务内 → 能取到 user
        User user = order.getUser();

        // 4. 返回携带user的DTO，而不是order对象 
        OrderDTO dto = new OrderDTO(order);
        dto.setUserName(user.getName());
        return dto;
    }
}

// Controller 里调用， 不会报错
OrderDTO orderDto = orderService.getOrder(1L);
orderDto.getUser(); 
```
