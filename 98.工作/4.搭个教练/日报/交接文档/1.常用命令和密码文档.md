# git
## 1. 拉取所有远程仓库的最新代码（包括 origin/master、origin/dev 等）
git fetch --all

## 2. 将当前 dev 分支，基于远程最新的 master 分支进行变基
1. rebase
git rebase origin/master
git reset --hard origin/master
2. 冲突时撤回上次rebase
  - git rebase --abort

## 3. 取消临时commit的东西
git reset --soft HEAD~1
