## 服务开通
1. 开通服务
2. 授权，创建 RAM 用户；
    - 授予系统策略 AliyunYundunGreenWebFullAccess；
    - 获取该 RAM 用户的 AccessKey ID 和 Secret（建议通过环境变量管理，避免硬编码）。
3. 引入 Java SDK
    - alibabacloud-green20220302 等 Maven 依赖
4. 调用审核接口
    - 编写调用代码，构造 TextModerationPlusRequest，传入待审核文本，调用 textModerationPlusWithOptions 方法。
