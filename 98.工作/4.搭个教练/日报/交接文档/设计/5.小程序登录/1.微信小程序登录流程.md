# 微信小程序登录
## 标准小程序登录流程
1. 小程序调用 wx.login() 获取 code`临时登陆凭证`
    1. 前端主动调用微信登录接口 wx.login()
    2. 这个 code 不包含用户信息，只是一个临时票据

2. 小程序将code传到后端
    1. 前端发起网络请求，把 code 发送到你自己的后端接口（比如 /api/wx/login）

3. 你的后端拿着 code + appid + appsecret 请求微信接口
    1. 微信官方接口 https://api.weixin.qq.com/sns/jscode2session
    2. 四个参数
        1. appid：小程序 ID（微信公众平台获取）
        2. secret：小程序密钥（必须保密，不能放前端）
        3. js_code：前端传过来的 code
        4. grant_type：固定值 authorization_code

4. 微信返回 `openid` 和 `session_key`
    1. openid：用户`在这个小程序里`的唯一标识（`终身不变`）
    2. session_key：加密密钥，用来解密用户信息（头像昵称等）
    - openid 和 session_key `绝对不能返回给前端`
    - 前端永远不应该拿到 openid，这是安全规范

5. 后端生成 `JWT token` 并返回给前端
    1. 后端：
        1. 根据 openid 查询 / 注册用户（数据库存用户表）
        2. 生成一个自定义登录凭证（JWT Token 等）
        3. 把 token 返回给小程序前端，后续接口只认 token，不认 deviceId 作为身份依据。
    2. 前端
        1. 把token保存到本地缓存（wx.setStorageSync）
        2. 后续所有请求都在 header 里带上 token
        3. 后端通过 token 识别当前登录用户


## 手机号绑定
- 前端调用getphone，获得一个code
- 后端用这个code调用微信接口，获取真实手机号
