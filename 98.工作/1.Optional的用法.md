# Optional
- Optional 最核心的适用场景是方法返回值和方法内临时变量，
## 核心场景
### 0. 创建Optional
1. `return Optional.ofNullable(T value);` , 最常用
2. `return Optional.empty();` , 如果需要返回空值的时候
3. Stream的一些`返回单个元素的方法`会返回Optional对象
    - findFirst(), findAny()
    - max(), min(), average()
    - reduce(BinaryOperator)
### 1. 方法返回值
1. 存在则处理
    - `opt.ifPresent(consumer)`
2. 存在则返回, 不存在则返回默认值
    - `opt.orElse()`
3. 存在则返回, 不存在则抛出异常
    - `opt.orElseThrow()`
```java
// 1.Service
public Optional<User> findUserById(Long id) {
    User user = userDao.selectById(id); // 数据库查询，可能返回null
    return Optional.ofNullable(user); // 自动处理null，返回Optional<User>
}

//2. Controller
// 2.1 存在则直接处理
userOpt.ifPresent(user -> sout(user));
// 2.2 存在则返回, 不存在则返回默认值
User user = userOpt.orElse(new User("默认用户"));
// 2.3 存在则返回, 不存在则抛出异常
User user = userOpt.orElseThrow(() -> new Exception("用户不存在"));
```

### 2. 流式处理的空值处理
- Stream 的中间操作 / 终止操作可能产生空值
```java
Optional<String> result = list.stream()
            .filter(str -> str != null && str.length() > 1)
            .findFirst();
// 处理结果
String value = result.orElse("默认值"); // 输出：默认值
```

### 3. 多层级对象访问
- user.getAddress().getCity(), 直接链式调用易因中间某层为 null 导致 NPE
```java
String city = Optional.ofNullable(user)
        .map(User::getAddress) // 如果user不为null，取address；否则返回空Optional
        .map(Address::getCity) // 如果address不为null，取city；否则返回空Optional
        .orElse("未知城市"); // 最终为空则返回默认值
```

### 4. Optional最佳实践
1. filter 条件过滤
2. map 转换(getXXX())
3. orElseThrow 为空是抛出异常
```java
String nickname = userOpt
    .filter(user -> user.getAge() > 18) // 过滤成年用户
    .map(User::getNickname) // 转换为昵称（String）
    .orElseThrow(() -> new RuntimeException("成年用户不存在")); // 空值兜底
```
4. flatMap() 可以解决 `嵌套 Optional（Optional<Optional<T>>）`问题
### 5. 不适合Optional的场景
- Optional只适合作为返回值或者临时变量, 用完即弃
1. Optional不适合作为方法参数
    - 方法参数直接在内部用`if(!=null)`判断
2. 不适合作为成员变量
    - Optional没有实现Serializable接口, 且会增大内存开销
