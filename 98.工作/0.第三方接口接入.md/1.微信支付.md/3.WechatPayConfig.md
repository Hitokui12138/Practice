## Java SDK
### 0. 配置文件
```yaml
wechat:
  pay:
    appid: wx1234567890abcdef # 你的小程序APPID, 小程序管理后台
    merchant-id: 1230000109 # 你的商户号, 微信支付商户平台
    private-key-path: classpath:cert/private.pem # 私钥路径
    merchant-serial-number: 1234567890ABCDEF # 商户证书序列号
    api-v3-key: 你的32位APIv3密钥 # APIv3密钥
```
### 1. 配置类接口 Config
- https://github.com/wechatpay-apiv3/wechatpay-java/blob/main/core/src/main/java/com/wechat/pay/java/core/Config.java
1. 一系列Get方法
    1. 微信商户号（mchid）
    2. APIv3 密钥, 用于解密微信支付的加密回调（如支付结果通知）
    3. 签名器（Signer）,用于给请求参数生成 RSA 签名（V3 接口必需）
    4. 验签器（Verifier）,用于验证微信返回数据的签名（防篡改）
    5.getHttpClient(), 获取 HTTP 客户端 —— 用于发送请求到微信支付接口
### 2. 抽象类 AbstractRSAConfig implements Config
- 封装RSA 签名相关的通用逻辑（复用代码）；
1. 具体的成员变量
    1. String merchantId, 商户号
    2. PrivateKey privateKey, 商户私钥
    3. String merchantSerialNumber, 商户证书序列号
    4. CertificateProvider, 微信支付平台证书Provider
    5. PublicKey, 微信支付平台公钥
    6. String publicKeyId, 微信支付平台公钥Id
### 3. 具体实现 RSAAutoCertificateConfig extends AbstractRSAConfig
- 实现证书自动管理的特有逻辑（具体落地）
1. 介绍
    - https://github.com/wechatpay-apiv3/wechatpay-java/wiki/SDK-%E9%85%8D%E7%BD%AE%E8%AF%A6%E8%A7%A3
    - 推荐使用这个, 因为它无需开发者人工维护微信支付平台证书，使用更简单更可靠。
2. 具体用法
    - https://github.com/wechatpay-apiv3/wechatpay-java/blob/main/core/src/main/java/com/wechat/pay/java/core/RSAAutoCertificateConfig.java
    ```java
    //1. 新建一个wxConfig类 @Configuration
    //2. 成员变量: 读取配置文件
    //3. 构造器: @Bean
    @Bean
    public Config wxPayConfig() {
        return new RSAAutoCertificateConfig.Builder()
            .merchantId(MERCHANT_ID)// 商户号
            .privateKeyFromPath(PRIVATE_KEY_PATH) // classpath: 前缀
            .merchantSerialNumber(MERCHANT_SERIAL_NUMBER)//商户证书序列号
            .apiV3Key(API_V3_KEY)//32位APIv3密钥
            .build();
    }

    // 3. 声明 JsapiService Bean（支付核心服务，全局复用）
    // JsapiService 作为官方 SDK 封装的服务类，已经帮你自动处理了HEADER等底层细节
    @Bean
    public JsapiService jsapiService(Config wxPayConfig) {
        return new JsapiServiceExtension().config(wxPayConfig);
    }
    ```

2. 返回给前端的`prepayId`的包装
- https://developers.weixin.qq.com/miniprogram/dev/api/payment/wx.requestPayment.html
```java
    private Map<String, String> generatePayParams(String prepayId) {
        // 3.1 构建基础参数
        String timeStamp = String.valueOf(System.currentTimeMillis() / 1000); // 时间戳（秒）
        String nonceStr = UUID.randomUUID().toString().replace("-", ""); // 随机字符串

        // 3.2 生成签名（SDK工具类自动处理RSA签名）
        // 签名参数：appId + timeStamp + nonceStr + package
        String packageStr = "prepay_id=" + prepayId;
        String paySign = PaymentSigner.signWithConfig(
                appid,        // 小程序APPID
                timeStamp,    // 时间戳
                nonceStr,     // 随机串
                packageStr,   // package参数
                wxPayConfig() // 全局Config（从Spring容器获取）
        );

        // 3.3 组装前端所需参数
        Map<String, String> payParams = new HashMap<>();
        payParams.put("appId", appid);
        payParams.put("timeStamp", timeStamp);
        payParams.put("nonceStr", nonceStr);
        payParams.put("package", packageStr);
        payParams.put("signType", "RSA"); // V3固定为RSA
        payParams.put("paySign", paySign); // 签名

        return payParams;
    }
```
