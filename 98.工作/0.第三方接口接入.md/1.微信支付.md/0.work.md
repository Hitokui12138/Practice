#
## WeChatConfig类
1. 四个内置类
    - MiniApp, App, Web, Pay(配置信息存在这里) 是做什么的
    - 读取 `wechat.pay`用的
2. @Bean的
    1. wxMaService
        - WeChat miniapp config
    2. WxMpService
        - WeChat web/app config
    3. `Config wechatPayConfig()`
        - 这里少传了私钥路径
    4. `JsapiService jsapiService(config)`, JSAPI 基础服务，用于下单/查单。
    5. JsapiServiceExtension, JSAPI 扩展服务，支持下单后直接生成前端调起参数。
    6. NotificationParser wechatPayNotificationParser, 回调解析器，负责微信回调的验签与解密
