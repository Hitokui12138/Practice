# Spring AMQP
1. 概念一览
    1. WorkQueue
    2. Fanout交换机
    3. Direct交换机
    4. Topic交换机
    5. 声明队列交换机
    6. 消息转换器
2. AMQP, Advanced Message Queuing Protocol
    - Spring AMQP 是基于AMQP协议定义的一套API规范
    1. spring-amqp, 是基础抽象
    2. spring-rabbit, 是底层默认实现
    ```xml
    <!-- RabbitMQ 依赖（继承根工程版本，无需手动指定） -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-amqp</artifactId>
    </dependency>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-test</artifactId>
        <scope>test</scope>
    </dependency>
    ```
## 测试1: 生产者 -> 队列 -> 消费者
1. 用控制台创建队列 `simple.queue`
### 生产者
1. 基础发送
    1. 简单文字消息
        1. `RabbitTemplate`
            - `rt.convertAndSend("simple.queue", "message");`
            - 自动序列化消息
        2. 调用后应该在控制台能看到
    2. 自定义对象
2. 生产级发送
    1. 发送带消息属性的消息（指定持久化、过期时间等）
    2. 发送延迟消息（适配 RabbitMQ 4.x 原生延迟队列）
    3. 同步发送（等待确认）
    4. 批量发送消息（提升性能）
### 消费者
1. 自动确认(测试用)
    1. `@Componennt` Class,消费端必须加 @Component：否则 Spring 无法扫描到监听方法，消息不会被消费
    2. 只要在方法名上标记`@RabbitListener(queue = "simple.queue")`即可
    3. `func(string msg)`, 只要参数这样写即可, Spring会帮你把消息取进来
    4. 缺点: 消费端抛异常也会确认，导致消息丢失
2. 手动确认(生产用)
    - 	需手动写确认逻辑, 避免消息丢失
