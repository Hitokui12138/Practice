# 消息转换器
1. 之前的消息类型都是String, 这次要求消息类型变成Map
    - rt.convertAndSend("object.queue", hashMap);
2. 虽然有默认的JDK序列化, 但是有安全漏洞
3. 一般建议采用 `JSON 序列化` 代替默认的 JDK 序列化

## jacksion
1. web-starter里面有这个, 如果不是web项目,则添加
    ```xml
    <dependency>
        <groupId>com.fasterxml.jackson.dataformat</groupId>
        <artifactId>jackson-dataformat-xml</artifactId>
    </dependency>
    ```
2. 分别在生产者和消费者中添加下面这个类即可
    ```java
    @Bean
    public MessageConverter jacksonMessageConvertor(){
        return new Jackson2JsonMessageConverter();
    }
    ```
