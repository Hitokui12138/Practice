# 也可以在Java中声明Queue和Exchange的绑定关系
1. SpringAMQP提供了几个类
    1. Queue, QueueBuilder, 用于声明队列
        - 队列不分种类,但是有`durable`和`nondurable`, 是否持久化这个队列
    2. Exchange, ExchangeBuilder, 用于声明交换机
        - 交换机有不同的实现
    3. Binding, BindBuilder, 用于声明绑定关系
2. 队列和交换机在`消费者`这一边声明
    - 因为发送者不关心队列
    - 需要在方法上加@Bean让他动态代理
## 1. 使用@Bean来操作
3. Fanout
    ```java
    @Bean
    func(){
        return ExchangeBuilder.fanoutExchange("hmall.fanout1").build();
    }
    @Bean
    func(){
        return QueueBuilder.durable("fanout.queue1").build();
    } 
    @Bean
    func(){
        return QueueBuilder.durable("fanout.queue1").build();
    }
    ```
## 2. 在@RabbitListener中操作
4. Direct
    1. 一条条绑定
        ```java
        ExchangeBuilder.directExchange("hmall.direct1").build();
        QueueBuilder.durable("direct.queue1").build();
        // 然后一条条设置,每条都需要一个方法
        BindingBuilder.bind(directQueue).to(directExchange).with("red");
        BindingBuilder.bind(directQueue).to(directExchange).with("blue");
        ```
    2. 基于@RabbitListener注解绑定
        ```java
        //以前
        @RabbitListener(queue = "simple.queue")
        //现在, 不需要一个一个Bean配置
        @RabbitListener(binding = @QueueBinding(
            value = @Queue(name = "direct.queue1", durable = "true"),
            exchange = @Exchange(
                name = "hmall.direct1",
                type = ExchangeTypes.DIRECT),
            key = {"red", "blue"}
        ))
        ```
