# Nginx进程模型
1. 一个master进程
    - 主要负责读取和验证配置文件
    - 管理worker进程
2. 多个worker进程

# 常用命令
1. 查看进程
    1. 如果是常规部署, 直接使用
        - `ps -ef | grep nginx`
    2. 如果是docker部署
        1. 直接看(执行一条命令，立刻返回结果，不进入容器)
            - `docker exec nginx ps -ef | grep nginx`
                - 没有 `-it`：不是交互式，执行完就退出
        2. 先进入容器, 再看
            - `docker exec -it nginx bash`
            - `ps -ef | grep nginx`
2. 查看80端口情况
    - `lsof -i:80`
