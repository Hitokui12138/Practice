# 正向代理与反向代理
1. 正向代理
    - 代理客户端与外网交涉
    - vpn之类的代理服务器, 代理客户端访问外网, 然后将结果返回客户端
    - 客户端知道请求通过了代理, 服务端不知道请求通过了代理
2. 反向代理
    - 代理服务端
    - 客户端访问一个网址, Nginx将请求转发给后端某一台服务器上
    - 客户端不知道请求通过了代理

# 测试
1. 创建端口号为8000,8001,8002三个go的web服务
2. 在配置文件中添加反向代理配置
    ```conf
    upstream goWeb {
        ip_hash;
        server 127.0.0.1:8000 weight=3; #可以调整权重
        server 127.0.0.1:8001;
        server 127.0.0.1:8002;
    }

    server {
        # 将所有/app开头的请求代理到上面的upstream中
        location /app {
            proxy_pass http://goWeb; #需要与上面名字一致
        }
    }
    ```
3. 之后访问 `locahost/app`即可, 请求会被转发给这三个web服务器上
    - 默认是`轮询`三个服务器
4. 调整负载均衡
    1. 在配置文件中调整权重
        - weight=3
    2. 根据ip分配
        - ip_hash;
