#
1. 查看当前Nginx的各项信息
    - `nginx -V`
        1. 主要是看`--conf-path=xxxx`, 配置文件的位置


# 用hexo生成静态站点
1. `hexo init demo`
2. `cd demo`
3. `hexo g`, 生成静态站点
    - 把md格式的文章, 转换成静态页面, 放在public文件夹下
4. `hexo s`, 启动本地hexo博客服务器(开发时)

# 因此把public下面的内容放在nginx服务器下面
1. docker rm -f nginx, 删除旧容器
2. 启动新容器
```shell
docker run -d \
--name nginx \
-p 80:80 \
-v $(pwd)/public:/usr/share/nginx/html \
--restart always \
nginx
```
