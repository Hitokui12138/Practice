# https
- http默认端口是80
- https默认端口时443
1. 首先要在云平台网站或者openssl上申请 `SSL证书`
    - 会得到`密钥文件.key`和`证书文件.pem`
    - 这两个文件要放在服务器上
2. 修改配置文件
```conf
# 重定向配置
server {
    listen 80;
    server_name: xxx;
    return 301 https://....
}
# ssl配置
server {
#    listen       80;
    listen       443 ssl;

    ssl_certificate       xxx/xxx.pem
    ssl_certificate_key       xxx/xxx.key

    #ssl 验证配置, 下面基本都是固定的
    ssl_session_timeout      5m; 缓存有效期
    可选加密协议;
    配套加密算法;
    首选算法;    
}
```
