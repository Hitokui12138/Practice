# Nginx
- 一个web服务器
1. C10K问题
    - 10000 concurrent connection 同时处理10000个并发连接

# Nginx的安装
1. 使用包管理器
    1. Linux
        - sudo apt update
        - sudo apt install nginx
    2. Mac
        - brew install nginx
    3. windows
        - scoop
        - choco
2. Nginx是用C语言编写的, 因此可以直接编译源码
    - 用于配置各种参数
3. Docker
    - docker pull nginx
