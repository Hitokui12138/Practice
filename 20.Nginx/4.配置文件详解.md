# 配置文件说明
- 全局配置和三个配置块
1. 最外面是全局配置
2. event块, 主要是服务器和客户端之间, 网络连接的相关配置
3. http块
    1. 虚拟主机
        - http块中有多个`server块`, 也叫虚拟主机
    2. 反向代理
    3. 负载均衡




# 配置文件示例
```conf

user  nginx;
worker_processes  auto; # 可以手动设置worker进程的数量

error_log  /var/log/nginx/error.log notice;
pid        /run/nginx.pid;


events {
    worker_connections  1024; # 每个worker进程最大能接受到多少个连接
}


http {
    include       /etc/nginx/mime.types; # 这个是用来判断css,html等文件类型的
    default_type  application/octet-stream;

    log_format  main  '$remote_addr - $remote_user [$time_local] "$request" '
                      '$status $body_bytes_sent "$http_referer" '
                      '"$http_user_agent" "$http_x_forwarded_for"';

    access_log  /var/log/nginx/access.log  main;

    sendfile        on;
    #tcp_nopush     on;

    keepalive_timeout  65;

    #gzip  on;

    include /etc/nginx/conf.d/*.conf;  # 当前文件为主配置,这个表示其他子配置文件
}
```

# 常用命令
1. `nginx -t`, 检查文件格式是否正确
2. `nginx -s reload`, 修改配置文件后重启一下
