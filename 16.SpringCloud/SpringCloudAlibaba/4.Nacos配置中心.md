# 配置
1. 创建一个 order-server 专用的
    1. Data ID: order-server.yaml
    2. 配置格式: yaml
    3. 配置内容:...
2. 给order引入新依赖:
    - `spring-cloud-starter-alibaba-nacos-config`
3. 在order的yaml文件中指定config的位置
    - spring.cloud.naocs.config.server-addr
    - spring.config.import
4. 然后就可以用 @Value("${author}") 读取配置文件了
5. 如果需要实时变化, 可以在类上加一个@RefreshScope的注解
