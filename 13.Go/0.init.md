1. 下载go语言安装包
    - `go version`
2. 创建文件夹, 初始化go项目
    - `go mod init github.com/Hitokui12138/go-get-started`
    -  自动创建一个go.mod文件, 是配置文件
3. VSCode安装支持Go的插件`Go Team at Google`
4. 写一个Hello World的入口文件
5. 命令行运行
    - `go run .`, 自动执行该目录的入口文件

## golong-IM-System
1.  创建服务器
    - `go build -o server main.go server.go`
    - 会生成一个服务器
2. 启动服务器
    - `./server`
3. 创建新的terminal进行测试
    - `nc 127.0.0.1 8888`
