- python3 --version
- Ctrl + D 退出

# 创建项目
1. 一般的项目
    - 直接创建 `main.py`
    - 执行`python main.py`
2. 工程化的环境
    1. 创建文件夹
    2. 在该文件夹中创建虚拟环境,名字一般叫 .venv
        - `python -m venv .venv`
    3. 激活虚拟环境
        - `source .venv/bin/activate`
    4. 搭建标准目录结构
        ```
        my_project/
        ├── .venv/              # 虚拟环境（不要把 .venv 提交到 git）
        ├── src/                # 源代码目录
        │   └── my_project/     # 业务包
        │       ├── __init__.py
        │       └── main.py
        ├── tests/              # 单元测试
        ├── pyproject.toml      # 项目配置、依赖（现代标准）
        ├── .gitignore          # git忽略文件
        ```
3. 手动创建
    1. src和tests文件夹
    2. pyproject.toml 
    3. .gitignore
        - 固定的，参考一下demo
4. 运行，右键文件， 选择`Run Python File in Terminal`
4. 方案 3｜使用 Poetry（现代化开发，强烈建议长期学习）
    - 适合需要打包、发布、严格依赖管理
