# 指针
1. 概念
    1. 内存地址: 每个变量在内存中都有唯一的地址
    2. 指针变量: 存储另一个变量的内存地址 的变量
2. 使用
    - `&` 是取得地址，`*` 是找变量以及声明指针。
    ```go
    var p *int //声明一个指针
    p = &v //取得变量v的地址, &v:取v的地址
    *p = 100 //解地址, 这一步`会修改v的值`, 等价于直接修改v = 100
    ```
    - 普通变量赋值是 “值拷贝”（复制一份值），指针赋值是 “地址拷贝”（复制一份地址）
    1. 需注意
        1. 指针`有类型约束`，*int 只能指向 int 变量，*string 只能指向 string 变量
        2. nil 指针没有指向任何变量，解引用会触发运行时 panic
3. 指针的优势
    1. `特别大的结构体`可以通过指针传递, 避免值重复拷贝的开销
    2. 指针传递 `在函数内`也可以影响外面的原变量
    3. 动态内存分配: 构建复杂的链表, 树结构
