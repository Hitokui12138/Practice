# map 映射
1. 存储`键值对`的`无序`集合
2. 映射是引用类型, 传递开销小
- map 必须用make(map[K]V, 容量)来定义
## 操作
```go
/*
1. 声明
*/
var m1 map[string]int //声明一个nil映射,无法赋值!
m2 := make(map[string]int) // 无初始容量（默认分配）
m3 := map[string]int{
    "apple": 5,
    "banana":6,
}

/*
2. 操作map
*/
m2["pear"] = 4 //插入或更新
delete(m2, "apple") //删除, 也是内置函数
value, exists := m2["检查是否存在"]
```
1. map并发不安全
    - 需要结合sync包的锁使用, 或者使用syncMap
2. 一种用法
    - 这里的interface表示的表示值可以是`任意类型`（字符串、数字、布尔等）
    ```go
    map[string]interface{}{
        "name": "张三",
        "age":  18,
    }
    ```
