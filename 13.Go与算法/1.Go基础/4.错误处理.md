# 错误处理
1. golong的错误类型
    ```go
    //1. error 内置接口类型
    type error interface{
        //需要实现一个error方法
        Error() string
    }

    //2. defer 延迟执行, 后进先出(堆栈?)
    defer func(){...}

    //3. panic/recover机制, 有点类似try catch
    //3.1 panic, 程序崩溃, 断触
    panic("错误消息")
    //3.2 通过recover恢复panic
    func recover() interface{}
    ```

2. 详细
    1. error: 数据库连接失败, 文件读写失败, 网络错误
        - 优先处理
    2. defer: 资源清理(关闭文件, 释放锁, 关闭数据库连接)
    3. panic/recover: 处理不可恢复的错误(数组越界)

## Error
- 自定义Error, 可以自定义一些Code和Message
## Defer
1. 不要在nil值上调用 defer 方法
    ```go
    file, err := os.Open(fileName)
    defer file.Close() // 错误：如果os.Open失败，file是nil，调用Close()会panic！
    ```
2. 循环内定义 defer 要谨慎（可能导致资源泄漏）
    ```go
    for i := 0; i < 1000; i++ {
        file, _ := os.Open("test.txt")
        defer file.Close() // 所有Close()要等函数结束才执行，会占用1000个文件句柄
    }
    ```
3. defer 定义后，其参数会 “立即求值”（不是执行时求值）
4. defer匿名函数：Panic发生时才会生效

## Panic/Recover
- 把 “致命 Panic” 变成 “普通错误”
1. Panic
    - 触发运行时崩溃（比如切片索引越界、nil 指针解引用），程序会终止执行并打印堆栈
2. Recover
    - 仅能在defer函数中调用，用于 “捕获” Panic，恢复程序执行，并返回 Panic 的原因；
    - 触发Panic时,程序会暂停, 然后执行Defer, 
        - 如果defer中调用了recover，Panic被捕获，程序恢复执行
        - 如果没有recover，程序崩溃退出
    ```go
    //defer匿名函数的定义方法
    defer func() {
		// 先新建一个r取得recover()的结果, 然后判断是否为空
		if r := recover(); r != nil {
			err = fmt.Errorf("发生Panic: %v", r)
		}
	}() //代码末尾的 () 是 Go 语言中匿名函数的 “立即调用” 语法
    ```
