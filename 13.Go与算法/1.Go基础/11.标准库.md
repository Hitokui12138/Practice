# Go 用户管理 HTTP 服务项目文档
## 一、项目概述
基于 Go 标准库实现的轻量级用户管理 HTTP 服务，无第三方框架依赖，核心功能为创建用户、查询单个用户、获取用户列表，支持配置文件+命令行参数管理，读写锁保证并发安全。

### 项目结构
```
Repo_test/
├── config/          // 配置管理模块
│   ├── config.go    // 配置加载/保存逻辑
│   └── config.json  // JSON 配置文件（端口、日志级别）
├── user/            // 用户核心业务模块
│   ├── user.go      // 数据层：用户结构体+存储逻辑（并发安全）
│   └── handler.go   // 控制层：HTTP 请求处理
├── go.mod           // Go 模块声明
└── main.go          // 程序入口：服务启动+路由注册
```

## 二、核心功能
1. **创建用户**
   核心实现代码：`handler.CreateUser(w, r)`（解析JSON请求体，调用AddUser存储）
2. **查询单个用户**
   核心实现代码：`handler.GetUser(w, r)`（解析路径ID，调用GetUser查询）
3. **获取用户列表**
   核心实现代码：`handler.GetUsers(w, r)`（调用GetAllUsers返回所有用户）
4. **启动HTTP服务**
   核心实现代码：`log.Fatal(http.ListenAndServe(fmt.Sprintf(":%d", config.Port), nil))`

## 三、关键标准库用法
1. **net/http**
   - 用途：HTTP服务/路由/响应
   - 核心代码示例：`http.HandleFunc("/users", func(w, r) { ... })`
   1. POST请求
        1. 定义方法
            1. Controller层
                1. CreateUser(w http.ResponseWriter, r *http.Request) {...}
                    - `w http.ResponseWriter`：「响应写入器」→ 是Go 用来构建 HTTP 响应的「唯一出口」
                    - `r *http.Request`：「请求对象」→ 读客户端的 “来信”, 这里用指针是避免大对象拷贝
                2. 读取请求体的JSON数据(Body)
                    1. body, err := `io.ReadAll(r.Body)`, HTTP 请求体是「流式数据」（不是一次性加载到内存）
                        - 通过函数返回值得知, Body是 []byte
                        - 完整JSON是`{"name":"Alice","email":"123@qq.com"}`, 但body是一个字符一个字符存储的
                    2. 读取之后需要关闭 defer r.Body.Close()
                    3. 反序列化见下节
                3. 向客户端发送信息
                    1. w.Header().Set("Content-Type", "application/json")
                    2. w.WriteHeader(http.StatusCreated) //201 Created
                    3. 序列化见下节, 只要写入w就能行, Go会`自动返回`

2. **encoding/json**
   - 用途：JSON编解码
   - 核心代码示例：
    - 反序列化: `json.Unmarshal(body, &req)` 
    - 序列化`json.NewEncoder(w).Encode(user)`
   1. 拿到`body []byte`,后进行反序列化
        - var req requestDTO
	    - if err := json.Unmarshal(body, &req); err != nil {...} , 反序列化的结果格式是提前定义好的, 因此直接赋值上去
    2. 两种反序列化的方法
        1. 分步反序列化再返回 
            - jsonBytes, err := json.Marshal(user),  需要生成`全新的 []byte 数据`, 因此两个返回结果
            - w.Write(jsonBytes)
        2. 写入response的同时反序列化
            - json.NewEncoder(w).Encode(user)

3. **sync**
   - 用途：并发安全（读写锁）
   - 核心代码示例：`s.mutex.Lock()` / `s.mutex.RLock()`（保护map操作）
4. **os+io**
   - 用途：文件读写
   - 核心代码示例：`content, err := io.ReadAll(os.Open(configFile))`
   1. 打开文件
        - file, err := os.Open(filename), 用os包打开文件（获取文件的 “访问句柄”）
        - defer file.Close()
    2. 读取文件
        - content, err := io.ReadAll(file), 读取结果是 `[]byte`
        - err = json.Unmarshal(content, &config), 对读取结果进行反序列化
5. **flag**
   - 用途：命令行参数解析
   - 核心代码示例：`flag.IntVar(&port, "port", 8080, "Port to run server")` + `flag.Parse()`
6. **strconv**
   - 用途：字符串转整数
   - 核心代码示例：`id, err := strconv.Atoi(strings.TrimPrefix(r.URL.Path, "/users/"))`
7. **strings**
   - 用途：字符串处理
   - 核心代码示例：`req.Name = strings.TrimSpace(req.Name)`
8. **time**
   - 用途：时间记录
   - 核心代码示例：`CreateAt: time.Now()`（用户创建时间）
9. **fmt**
   - 用途：格式化输出
   - 核心代码示例：`addr := fmt.Sprintf(":%d", config.Port)`
10. **log**
    - 用途：日志/服务退出
    - 核心代码示例：`log.Fatal(http.ListenAndServe(addr, nil))`

## 四、核心代码片段
### 1. 配置文件（config/config.json）
```json
{
    "port" : 8000,

```

### 2. 用户数据层（user/user.go 核心）
```go
// 用户结构体
type User struct {
    ID       int       `json:"id"`
    Name     string    `json:"name"`
    Email    string    `json:"email"`
    CreateAt time.Time `json:"create_at"`
    Active   bool      `json:"active"`
}

// 新增用户（写锁保护）
func (s *UserStore) AddUser(name, email string) User {
    s.mutex.Lock()
    defer s.mutex.Unlock()
    user := User{ID: s.nextID, Name: name, Email: email, CreateAt: time.Now(), Active: true}
    s.users[s.nextID] = user
    s.nextID++
    return user
}
```

### 3. HTTP处理层（user/handler.go 核心）
```go
// 创建用户
func (h *UserHandler) CreateUser(w http.ResponseWriter, r *http.Request) {
    body, _ := io.ReadAll(r.Body)
    var req struct{Name, Email string `json:"name,email"`}
    json.Unmarshal(body, &req)
    user := h.store.AddUser(strings.TrimSpace(req.Name), strings.TrimSpace(req.Email))
    json.NewEncoder(w).Encode(user)
}
```

### 4. 程序入口（main.go 核心）
```go
func main() {
    flag.StringVar(&configFile, "config", "config.json", "Config file path")
    flag.Parse()
    config, _ := config.LoadConfig(configFile)
    handler := user.NewUserHandler(user.NewUserStore())
    http.HandleFunc("/users", func(w, r *http.Request) {
        switch r.Method {
        case http.MethodPost: handler.CreateUser(w, r)
        case http.MethodGet: handler.GetUsers(w, r)
        }
    })
    http.HandleFunc("/users/", handler.GetUser)
    log.Fatal(http.ListenAndServe(fmt.Sprintf(":%d", config.Port), nil))
}
```

## 六、核心设计亮点
1. **分层解耦**：数据层（UserStore）与控制层（UserHandler）分离，依赖注入实现解耦；
2. **并发安全**：读写锁（RWMutex）保护用户数据map，读并发、写互斥；
3. **配置灵活**：支持配置文件+命令行参数，优先级：命令行 > 配置文件；
4. **原生实现**：无第三方框架，纯Go标准库完成HTTP服务开发。
