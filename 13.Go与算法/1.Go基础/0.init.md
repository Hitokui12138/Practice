1. 下载go语言安装包
    - `go version`
2. 创建文件夹, `初始化go项目`
    - `go mod init github.com/Hitokui12138/go-get-started`
        - 一般是仓库地址，没有仓库也可以随便写
    -  自动创建一个go.mod文件, 是配置文件
3. VSCode安装支持Go的插件`Go Team at Google`
4. 写一个Hello World的入口文件
5. 命令行运行
    - `go run .`, 自动执行该目录的入口文件

## golong-IM-System
1.  创建服务器
    - `go build -o server main.go server.go`
    - 会生成一个服务器
2. 启动服务器
    - `./server`
3. 创建新的terminal进行测试
    - `nc 127.0.0.1 8888`

## golong的指针
1. golang中所有类型都是`值类型`(struct也是)
    - 举一个链表的例子
    ```java
    // Java 把指针封装成「引用」，开发者不用关心地址
    class Node{
        int val;
        Node next; //指向另一个Node对象的引用
    }
    //创建节点
    Node node1 = new Node(1);
    Node node2 = new Node(2);
    //构建链表
    node1.next = node2;
    ```
    ```go
    // Go 保留指针概念，让开发者明确知道「当前变量是值还是指针」。
    type Node struct {
        val int
        next *Node //指向另一个Node的指针
        //用 *T 声明指针类型
    }
    //创建节点
    //
    node1 := &Node{val: 1} //&取地址, 相当于
    var nodeVal Node = Node{val: 1}
    var node1 *Node = &nodeVal 
    //构建链表
    node1.next = node2  
    ```
