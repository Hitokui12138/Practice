## 数组与切片
1. 数组
    0. 数组`必须定义长度`
    1. 值类型, 类似于String, 当数组赋予一个新变量或者传递给函数时, 会`创建一个新副本`
    ```go
    //声明一个数组
    var arr1 [3]int //固定长度
    arr2 :=[3]int{1,2,3}
    arr3 :=[...]int{1,2,3,4,5}  //也是固定长度, 不过是让编译器自己计算
    ```
2. 切片
    0. 切片是数组的抽象, 是可变的, `定义时, 不能有长度`
    1. 引用类型
    2. 包含三个组件: 指向底层数组的指针, 长度, 容量
    3. 扩容机制
        1. 小于1024时, 翻倍
        2. 大于1024时, 每次扩容增加25%左右
    ```go
    //声明一个切片
    var slice1 []int //不写初始长度
    slice2 := []int{1, 2, 3} //不写长度
    slice3 := make([]int, 3, 5) //使用make(), 长度3, 容量5
    slice := arr2[1:3] //由数组创建, 生成的是一个切片而不是数组
    ```
## 切片的增删改
1. 增
    - slice = append(slice, elem...)
    1. 为什么不是 slice.append(element) ?`方法调用`
        1. append(slice, elem...)是`内置函数`
            1. 避免为基础类型（切片本质是数组的封装）增加方法, 避免过度面向对象
            2. 方法接收者若为值类型会拷贝切片，若为指针类型违背直觉，内置函数更易处理；
            3. 内置函数支持 “多参数 +... 展开”
## make() 方法
- make() 是 Go 内置函数，专门用来创建「引用类型」（切片 slice、映射 map、通道 channel）并初始化其底层数据结构，返回的是类型本身（而非指针）
- make(类型, 长度, 容量) // 容量可选（仅 slice 需要，map/channel 忽略）
1. 这个容量有什么用?
    - 核心场景：提前指定切片容量，避免频繁扩容（提升性能）。
