# Go的工具链
1. go mod , 管理模块依赖
2. go build , 编译Go程序, 生成可执行文件
3. go run ,编译并且运行
4. go test , 用于运行测试
5. go get , 添加依赖包到模块
6. go install, 
7. go fmt
8. get vet
9. go doc
## 最常用
1. go run
    - go run main.go -port 8080 ,运行主程序，支持传命令行参数
    - go run ./cmd/server ,指定目录
2. go build
    - go build -o user-server main.go ,编译为指定名称的可执行文件
    - 打包你的用户管理服务，部署到服务器
3. go mod
    1. go mod init：初始化项目（生成 go.mod，比如 go mod init repo-test）
    2. go mod tidy：自动清理未使用的依赖、下载缺失的依赖
    3. go get：安装 / 升级依赖（比如 go get go.etcd.io/etcd/client/v3）；
4. go test
    - 运行测试代码（以 _test.go 结尾），支持单元测试、基准测试、覆盖率分析
    1. go test：运行当前目录的所有测试；
    2. go test -v：显示详细测试日志；
    3. go test -cover：查看测试覆盖率；
    4. go test -bench=.：运行基准测试（性能分析）

## 中频
1. go fmt / go fmt ./...：代码格式化（统一风格）
    - go fmt ./... , 格式化当前文件目录下所有代码
2. go vet ./... 静态代码检查
    - 发现你之前遇到的 ST1000 包注释问题
    - 提交代码前、编译前必跑，比编译器更早发现问题
3. go doc fmt , 断网时查看某个包的用法
4. go clean -r -cache ,删除编译生成的可执行文件、缓存、测试二进制文件；
5. go list
    1. go list -m ,列出项目所有直接依赖
    2. go list -m all ,列出所有依赖（包括间接依赖）
