## Sort包的使用
- go的标准库, 可以对切片或者用户自定义集合进行排序
## 常见用法
```go
//1. 基本类型
sort.Ints(slice []int)
sort.Float64s(slice []float64)
sort.String(slice []string)

//2. 自定义排序 comparator匿名函数
sort.Slice(slice, func(i, j int)bool{
    return slice[i]<slice[j]
})

//3. 先让你的struct实现下面这个sort.Interface接口
type Interface interface{
    len() int,
    Less(i,j,int)bool
    Swap(i,j,int)
}
sort.Sort(slice) //然后直接调用这个方法
```
