# Go的"面向对象"
- 不是完全面向对象, 通过接口,结构体,方法来实现面向对象的逻辑
1. Go使用`组合替代继承`
    1. Go 不支持类的继承（没有extends/implements关键字），而是通过 `将一个结构体嵌入另一个结构体` 的组合方式
        1. 继承: is-a，狗是一种动物, 子类 “继承” 父类的属性和方法
        2. 组合: has-a, Dog嵌入Animal，狗有动物的属性 / 方法
            - 多组合实现 “多继承” 的效果，且解耦
        ```go
        type Animal struct {
            Name string
            Age  int
        }

        // Animal的Eat方法
        func (a *Animal) Eat() {
            fmt.Printf("%s在吃东西\n", a.Name)
        }

        // 组合：Dog嵌入Animal（has-a：狗有Animal的属性/方法）
        type Dog struct {
            // 嵌入Animal结构体（无需字段名，直接写类型）
            Animal
            // 可新增Dog独有的字段
            Breed string
        }

        // Dog独有的方法
        func (d *Dog) Bark() {
            fmt.Printf("%s（%s）汪汪叫\n", d.Name, d.Breed)
        }
        // 重写（覆盖）Eat方法：仅影响Dog，不影响Animal
        func (d *Dog) Eat() {
            fmt.Printf("%s（%s）吃骨头\n", d.Name, d.Breed)
        }

        // 也可以显式访问嵌入结构体的方法（绕过覆盖）
        dog.Eat() //调用Dog的Eat()
        dog.Animal.Eat() //调用Animal的Eat()
        ```
    2. Java是组合+继承
        - Java 的所有类最终都继承自Object类 —— 这是 Java 类型系统的核心设计：Object提供了所有类的基础方法（equals()、hashCode()、toString()等）；
        - 若没有继承，每个类都需要手动组合Object的功能，会导致代码冗余到无法维护；
        - 而 Go 没有统一的根类型，每个类型都是独立的，因此可以彻底抛弃继承
