# Gin
1. 首先安装第三方库
    - `go get github.com/gin-gonic/gin`
    - Go 和 Node/npm 不一样：没有全局 Gin 一说， 因此必须在go.mod中安装Gin框架
2. 使用流程
    1. 初始化 Gin 引擎
        - r := gin.Default()
    2. 写路由
        - r.GET("index", index)， index方法需要定义一下
    3. 监听运行
        - r.Run(":8080")
            1. `:8080`,内网其他人也能访问
            2. `127.0.0.1:8080`,回环地址，仅本机能访问
3. 优化
    1. 默认Gin引擎是DeBug模式
        - 如果不想看太多log可以设为`release`模式

# Gin提供多种响应方式
1. JSON
    ```go
    // c *gin.Context
    c.JSON(
        200, //状态码
        gin.H{ //H是gin定义的一个Map
            "code": 10001,
            "msg": "成功"，
            "data": gin.H{
                "name": "张三"
            } 
        }
    )
    ```
