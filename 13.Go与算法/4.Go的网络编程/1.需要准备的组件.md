# 各组件对应你的业务需求说明
1. Gin：对外暴露接口，接收客户端请求
2. resty：内部发起 HTTP 请求调用外部第三方 API
3. gobreaker：第三方服务挂了不会拖垮自己服务
4. Redis：缓存第三方返回数据，降低调用频次、限流防刷
5. zerolog：记录每一次第三方调用的地址、耗时、错误，方便排障
6. Viper：统一管理第三方密钥、接口地址、超时时间，不硬编码
7. GORM：记录调用流水，用于对账、问题追溯
8. Prometheus：监控第三方接口故障率，提前告警

# 必学的标准库
0. 数据库 主流方案是 GORM
1. net/http（Web/HTTP 底层核心）
    - 必掌握：http.Request、http.ResponseWriter、http.Client、http.Transport、超时、长连接
    1. 可能会用到
        1. net/url， 解析、拼接第三方 API 地址，处理 Query 参数
        1. crypto 系列（第三方接口签名、数据加密）
2. encoding/json（JSON 序列化 / 反序列化）
    - 业务核心，前后端交互、第三方 API 请求响应全是 JSON
3. context（上下文控制，服务并发灵魂）
    - 所有网络请求、接口、第三方调用必须带 ctx
4. io /io/ioutil（Go1.16+ ioutil 已废弃，用 io、os）
    - 处理流数据：接口 Body、文件读写、日志、上传下载
5. time（时间处理无处不在）
    - 场景：接口超时、日志打印时间戳、接口耗时统计、缓存过期时间
6. sync（并发安全，多协程调用第三方接口必用）

# 项目中可能会用到的
1. os（系统、环境变量、文件）
    - 读取环境变量（第三方密钥、服务端口），程序退出、信号监听
2. fmt / log
    - log：基础打印，生产会替换 zap/zerolog，但调试必用
3. errors（错误处理，Go1.13+）
    - 场景：封装第三方 API 调用错误、区分业务错误 / 网络错误
4. strconv（字符串与数字互转）
    - 解析 URL 参数、第三方返回字符串数字、配置文件数值转换
