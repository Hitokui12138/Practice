# 参数
- 用的最多的是下面的Bind绑定器
1. 查询参数
    - 不是GET专属的
    - ?key=123&key=456&name=xxx
2. 动态参数
3. 表单参数
4. 文件上传

# 参数取得（这些都是很老的方法）
1. 查询参数
    - `?key=123&key=456&name=xxx`
    ```go
    r.GET("url", func(c *gin.Context){
        keyList := c.QueryArray("key")
        name := c.Query("name")
        age := c.DefaultQuery("age", 25)
    })
    ```
2. 动态参数
    - `users/{123}/{456}`
    ```go
    r.GET("users/:id/:name", func(c *gin.Context){
        userId := c.Param("id")
        userName := c.Param("name")
    })
    ```

3. 表单参数
    - `POST /users`
    ```go
    r.POST("users", func(c *gin.Context){
        name := c.PostForm("name") //1. 这个方法无法区分是穿了为空还是没穿
        age, ok := c.GetPostForm("age") //2. 这个方法如果没传，ok为false
    })
    ```

4. 文件上传
    - postMan可以选择参数为文件
    - `fileHeader`里面包含文件名，文件大小等信息
    - `File`对象中包含 io.Reader 等信息
    ```go
    r.POST("users", func(c *gin.Context){
        fileHeader， err := c.Formfile("file")
        if err != nil {
            return
        }

        //file, _ := fileHeader.Open()
        //byteData, _ := io.ReadAll(file) //因为file中有 io.Reader
        //os.WriteFile("xxx.jpg", byteData, 0666)

        c.SaveUploadedFile(fileHeader, "xxx/xxx"+fileHeader.Filename)

    })
    ```

# Bind绑定器
1. 查询参数
```go
// 要写成 `form:"xxx"`格式
type User struct{
    Name string `form:"name"`,
    Age int `form:"age"`
}

r.GET("url", func(c *gin.Context){
    var user User
    err := c.ShouldBindQuery(&user) // 会自动根据struct结构来校验，映射参数
    fmt.Println(user, err)
})
```

2. 路径参数
```go
// 要写成 `uri:"xxx"`格式
type User struct{
    Name string `uri:"name"`,
    Age int `uri:"age"`
}

r.GET("url/:name/:age", func(c *gin.Context){
    var user User
    //err := c.ShouldBindQuery(&user) // 会自动根据struct结构来校验，映射参数
    err := c.ShouldBindUri(&user)
    fmt.Println(user, err)
})
```

3. 表单参数
    - 不能解析`x-www-form-urlencoded`格式
```go
// 要写成 `form:"xxx"`格式
type User struct{
    Name string `uri:"name"`,
    Age int `uri:"age"`
}

r.GET("url", func(c *gin.Context){
    var user User
    //err := c.ShouldBindQuery(&user) // 会自动根据struct结构来校验，映射参数
    //err := c.ShouldBindUri(&user)
    err := c.ShouldBind(&user)
    fmt.Println(user, err)
})
```

4. JSON参数（重要）
```go
// 要写成 `json:"xxx"`格式
type User struct{
    Name string `json:"name"`,
    Age int `json:"age"`
}

type Header struct{
    sso string `header:"sso"`,
    ContentType string `header:"Content-Type"`
}

// 这里是POST
r.POST("url", func(c *gin.Context){
    var user User
    var header Header
    err := c.ShouldBindJSON(&user) //请求体
    err := c.ShouldBindHeader(&header) //请求头
    fmt.Println(user, err)
})
```

# Binding 内置规则
```go
type User struct{
    // Name string `json:"name"` 
    Name string `json:"name" binding:"required,min=5"` 
    Age int `json:"age"`
}
```
1. 常用
    1. binding:"required"
    2. binding:"min=5" ，针对字符串长短
        - max=10， len=6
    3. binding:"eq=3"， 针对数字大小
        - eq， ne
        - gt， gte
        - lt， lte
    4. 对比同级其他字段
        - newPW string `json:"newPW" binding:"nefield=oldPW"` 
        - eqfield
    5. 枚举
        - oneof=red green
    6. 字符串
        - contains=abc
        - excludes
        - startswith, endswith
    7. 数组
    8. 网络验证
        - ip，url
    9. 日期验证
