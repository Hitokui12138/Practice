# Gin的路由
1. 常见路由方式
    1. r.POST()
    2. r.GET()
    3. r.PUT()
    4. r.PATCH()
    5. r.DELETE()
2. r.ANY(), 允许所有请求方式
3. 对路径进行分组
    - 访问 `api/v1/users`
    ```go
    main(){
        r := gin.Default()

        apiGroup := r.Group("api/v1")
        UserGroup(apiGroup) //这样就绑定上了

        r.Run(":8080")
    }

    func UserView(c *gin.Context){
        path := c.Request.URL
        fmt.Println(path)
    }

    func UserGroup(r gin.RouterGroup){
        r.GET("users", UserView)
        r.GET("user", UserView)
        r.POST("user", UserView)
    }
    ```
