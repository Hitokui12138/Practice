# 创建一个web服务
1. `http.ListenAndServe("0.0.0.0:8080", nil)`
    - 这样就可以了，0.0.0.0表示这台机器的所有IP
    - 但是这条命令会`阻塞后续操作`，因此定义路径执行的方法的代码应该写在上面
2. 描述逻辑, 调用/index时，触发后面的函数
    - http.HandleFunc("/index", index)
    1. 请求方式
        - 这个方法可以接受`所有请求方式`，都会调用这个函数
        - 需要在函数内部进行判断到底用的是那种请求方式
```java
func main() {
	//1. 描述逻辑, 调用/index时，触发后面的函数
	http.HandleFunc("/index", index)
	fmt.Println("Http 服务正在运行： 127.0.0.1:8080")
	//2. 创建一个地址，监听所有IP的8080端口,阻塞这个进程
	http.ListenAndServe(":8080", nil)
}

func index(w http.ResponseWriter, r *http.Request) {
	// 打印请求方式和参数
    // GET /index?key=123 map[Accept:[*/*] User-Agent:[curl/8.7.1]]
	fmt.Println(r.Method, r.URL.String(), r.Header)
	// 若请求方法不是GET，尝试拿一下Body参数
	if r.Method != "GET" {
		byteData, _ := io.ReadAll(r.Body)
		fmt.Println(string(byteData))
	}

	// 响应部分
	w.Write([]byte("Hello World!"))
}
```

3. 测试
    1. 发起 GET 请求
        - curl http://127.0.0.1:8080/index\?key\=123
    2. 发起 POST 请求
        - 使用POSTMan


4. 原生http服务的缺点
    1. 不同请求方式的参数有不同的格式， `参数解析`很麻烦
    2. 一个`路由`就把所有请求方式给涵盖了， 再在方法中判断请求方式很麻烦
    3. `响应处理`比较原始，想返回JSON的话也比较蛮烦


# 调用第三方API
1. 创建全局的 HttpClient
2. 在方法中 构建POST请求参数，JSON格式
3. 定义要访问的URL，请求方式，以及设置Header，告诉对方我们传的是JSON
4. 发送请求，接受结果
    - 最后resp.Body 必须 defer Close ()
