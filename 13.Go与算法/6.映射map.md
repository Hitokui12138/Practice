# map 映射
1. 存储`键值对`的`无序`集合
2. 映射是引用类型, 传递开销小
## 操作
```go
/*
1. 声明
*/
var m1 map[string]int //声明一个nil映射,K是string, V是int
m2 := make(map[string]int)
m3 := map[string]int{
    "apple": 5,
    "banana":6,
}

/*
2. 操作map
*/
m2["pear"] = 4 //插入或更新
delete(m2, "apple") //删除, 也是内置函数
value, exists := m2["检查是否存在"]
```
1. map并发不安全
    - 需要结合sync包的锁使用, 或者使用syncMap
