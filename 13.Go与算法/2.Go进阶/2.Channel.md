# Channel
- Channel是各个并发执行体`之间的通讯机制`, 用于在Goroutine之间传递数据和同步执行
- CPS:`不要通过共享内存来通信，要通过通信来共享内存`
1. Channel的操作
    ```go
    //1. 定义Channel
    ch := make(chan int)    //无缓存的Channel, 同步通讯, 发送者和接收者必须同时准备好
    ch := make(chan int, 10) // 带缓存的Channel, 缓存大小为10, 异步通讯, 缓存满时发送阻塞, 缓存为空时接收阻塞

    //2. 操作
    //2.1 发送操作
    ch <- 10 // 发送10到Channel ch
    //2.2 接收操作
    x := <-ch // 从Channel ch接收数据, 并赋值给变量x
    //2.3 关闭Channel
    close(ch) // 关闭Channel ch, 后续发送操作会 panic, 接收操作会返回零值

    //特殊
    value, ok := <-ch // close()之后可以读, 看看到底有没有关闭
    ```
2. Channel的应用场景
    1. 多个Goroutine之间的通讯, 协调传递数据
    2. 任务分发, 生产者消费者模型
    3. 结果收集, 聚合多个并行任务的结果
    4. 同步控制(替代锁), 超时控制(配合定时器)
