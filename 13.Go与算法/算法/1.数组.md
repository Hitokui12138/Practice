# 数组（顺序存储）
1. 两类
    1. 静态数组
        - 「静态数组」就是一块连续的内存空间，我们可以通过索引来访问这块内存空间中的元素，这才是数组的原始形态。
    2. 动态数组
        - 「动态数组」是编程语言为了方便我们使用，在静态数组的基础上帮我们添加了一些常用的 API
## 增删改查
```go
//1. 静态数组
var array [10]int{1,2}
//2. 动态数组(自动扩缩容)
arr := make([]int, 0)

```
1. 原理解释
    - 在内存中开辟了一段连续的内存空间，大小是 10 * sizeof(int) 字节。一个 int 在计算机内存中占 `4 字节(32 bit)`，内存是连续的, 也就是array总共 40 字节。
    - 定义了一个名为 arr 的数组指针，指向这段内存空间的首地址。
    - arr[1] 就是 arr 的首地址加上 1 * 4 字节
2. 复杂度计算
    1. 计算机的内存寻址时间可以认为是 O(1), 所以数组的随机访问时间复杂度是 O(1)。(`查和改都很快`)
    2. 对末尾的增删也是O(1), 因为给定了特定索引
3. 如何实现`往中间insert一个元素`
    - 前 4 个位置装了元素，现在想在第 3 个位置插入一个新元素, 则需要把索引 2 以及之后的元素都往后移动一位(数据搬移)
    - 复杂度为O(N), 因为索引后每个元素都要移动
4. 如何`从中间delete一个元素
    - 数据搬移，把被删元素后面的元素都往前移动一位，保持数组元素的连续性`
    - 复杂度为O(N)
4. 超出长度怎么办
    - 连续内存必须一次性分配，分配完了之后就不能随意增减了。因为你这块连续内存后面的内存空间可能已经被其他程序占用了，不能说你想要就给你。
    - 只能重新申请一块更大的内存空间`[20]int`，把原来的数据复制`[10]int`过去，再插入新的元素，这就是数组的「扩容」操作。
    - 每个数都要复制, 因此复杂度为O(N)

## 动态数组
1. 动态数组应该有几个关键点
    1. 自动扩缩容
    2. 索引越界检查
    3. 有些语言可能需要考虑删除元素后的内存泄露
