# 1.数组
```java
/** 1. 数组 */
//1. 创建
int[] arr = new int[10]; //固定长度的空数组
int[] arr = {1, 2, 3, 4}; //固定长度的数组
int len =  arr.length; //这不是个方法
return new int[]{1,2};

//2. 打印, 一定要先转字符串(只能用静态方法)
sout(arr); // [I@1b6d3586, 直接打印是地址值
Arrays.toString(arr); //[1, 2, 3, 4], 有奇怪的空格
Arrays.toString(arr).replace(" ", ""); // 没有空格但是有方括号[1,2,3,4]

//2.1 不想要中括号,手动拼接
StringBuilder sb = new StringBuilder();
for(){
    if(i > 0) sb.append(",")
    sb.append(arr[i])
}// 1,2,3,4

//3. 其他方法
Arrays.sort(arr); //排序

//4. 判定是否为空
if (arr == null || arr.length == 0) return new int[]{};

//5. ArrayList转数组
List<Integer> list = new ArrayList<>();
int[] result = list.stream().mapToInt(i -> i).toArray();
```

# 3. Map
- 给一堆数, 让判断有没有两个数能凑成目标(一边找一边存); 统计每个数出现了几次
```java
Map<Integer, Integer> map = new HashMap<>();
//set, get
//1. 最常用, 判断有没有这个键 (极其常用！), 但是不能判断是否存在一个值
map.containsKey(键);

//2. (过时)遍历Map,Map 并不会直接暴露内部的键或值给你遍历，而是提供了一个叫 entrySet() 的方法。这个方法会把 Map 里所有的 Entry 对象打包成一个集合返回, 然后遍历这个集合
for(Map.Entry<Integer, Integer> entry : map.entrySet()){
    int key = entry.getKey();
    int value = entry.getValue();
}

//2. 遍历
map.forEach((k, v) -> sout(k + ":" + v))
```

# 4. ArrayList
- 不知道有多少个结果; 对一堆数据进行排序
```java
List<Integer> list = new ArrayList<>();

//1. 常用
list.add(1); //在末尾添加
list.size(); //不是length哦
list.set(i, 新元素); //改

// 2. 排序(重要,这里用的静态方法)
Collections.sort(list);
Collections.sort(list, Comparator); 
list.sort(Comparator); //前者的简化,必须填一个比较器
```
