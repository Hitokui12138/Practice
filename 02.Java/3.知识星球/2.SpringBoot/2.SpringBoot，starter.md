# SpringBoot
## 1. 概念
### 1.1 SpringBoot Starter
1. 什么是SpringBoot Starter
    - 表示一组的依赖, 预先打包了常用的库和配置
    - 这显著简化了开发流程
2. 常见
    1. spring-boot-starter
        - Spring框架本身, 日志系统(SLF4J和Logback)
    2. spring-boot-starter-web
        - RESTful服务, SpringMVC, Tomcat, Jackson
    3. spring-boot-starter-data-jpa
        - spring data jpa 和 Hibernate
    4. spring-boot-starter-test
        - JUnit, Mockito, Spring Test, 单元测试, 集成测试, Mock测试
    5. spring-boot-starter-aop
        - Spring AOP和 AspectJ
    6. spring-boot-starter-validation
        - Hibernete Validator等JavaBean校验机制
### 1.2 自动配置机制
- @SpringBootApplication里面的`EnableAutoConfiguration`是自动配置的核心
1. 自动配置原理
    1、引入Starter组件
    2、SpringBoot基于约定去Starter组件的路径下（META-INF/spring.factories）去找配置类
    3、SpringBoot使用ImportSelector去导入这些配置类，并根据@Conditional动态加载配置类里面的Bean到容器
## 2 常用注解
1. `@SpringBootApplication`
    - 用于标记程序的main()方法, 可以看作:
    1. `@SpringBootConfiguration`
        - 表示被标记的类是一个配置类
    2. `@EnableAutoConfiguration`
        - 启动SpringBoot自动配置机制, 这是自动配置的核心
    3. `@ComponentScan`
        - 启动组件扫描
2. Bean相关的注解
    1. @Autowired(按类型)/@Qualifier(按名称)
    2. @Configuration + @Bean, 手动配置Bean
        1. 常用场景:
            - 配置第三方库的类: `RedisTemplate`
    3. @Controller/ @Service/ @Repository/ @Component
        - 底层功能完全一致：都能把类交给 Spring IOC 容器管理、实例化为 Bean；区别仅在于语义分层、编译校验、底层附加功能，用于代码分层规范。
    4. @RestController
        - @Controller + @ResponseBody
        - 表示这是一个控制器的Bean, 控制器方法直接返回 自动将返回值序列化为 JSON
3. Bean的作用域 `@Scope()`
    1. singleton
        - Spring 容器启动时创建（默认懒加载），整个应用中只有一个实例
        - 随 Spring 容器启动而创建，容器销毁而销毁
    2. prototype
        - 每次获取 / 注入 Bean 时，都创建新实例
        - Spring 容器创建后不再管理，不会调用销毁方法
        1. 适用场景:
            - 有状态的对象（如包含可变属性的业务对象、请求上下文对象）—— 每次使用都需要新实例，避免多线程共享状态导致的问题。
    3. 四个Web相关的
4. HTTP相关
    1. 请求 @GetMapping @PostMapping
    2. 传递参数:
        1. GET
            - @RequestParam
            - @Pathvaribale
        2. POST
            - @RequestBody

### 3.1 读取配置文件的方式
1. 直接读取一个值
    - @Value("${wuhan2020}"), `不推荐`
    - String wuhan2020;
2. 将读取的值与一个Bean绑定(常用)
    - @ConfigurationProperties(prefix = "library") , 写在类名上
        - private String location;
        - private List<Book> books; //可以直接读进`列表`
3. 读取指定的配置文件
    - @PropertySource("classpath:website.properties")

- https://mp.weixin.qq.com/s?__biz=Mzg2OTA0Njk0OA==&mid=2247485783&idx=1&sn=a407f3b75efa17c643407daa7fb2acd6&chksm=cea2469cf9d5cf8afbcd0a8a1c9cc4294d6805b8e01bee6f76bb2884c5bc15478e91459def49&token=292197051&lang=zh_CN#rd

1. 已经提供很多注解
    1. @NotNull , 
        - 任意类型不为null
    2. @NotEmpty
        - String, Collection, Map, Array 不能为null, 且长度不能为0
    3. @NotBlank
        - String, 不能为null, 也不能为空格字符串

        2. func(@PathVarible("id" @NotBlank("msg") String ID))
    2. 对于POST方法的 @RequestBody
        1. 不用在类上加注解
        2. func(@RequestBody @Valid Person person)
## 7. 定时任务
### 7.1 如何启动一个定时任务
1. 在启动类上加注解`@EnableScheduling`注解
2. 在需要定时执行的方法上面加注解`@Scheduled(fixRate = 5000)`
### 7.2 多节点部署时, 如何防止定时任务重复执行?
1. 分布式锁
    1. 利用Redis, Zookeeper等中间件实现分布式锁, 确保同一时间只有一个节点可以获得锁并触发相应的任务
    - https://javaguide.cn/distributed-system/distributed-lock-implementations.html
2. 其他方法(java定时任务详解)
    - https://javaguide.cn/system-design/schedule-task.html
