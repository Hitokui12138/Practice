## 8.JUC 工具类(Java 同步器)
### 1. CountDownLatch ，模拟高并发场景， 秒杀场景，并行计算
1. `CountDownLatch`，倒计时门闩（让子线程等待）
    - 多个线程运行到`门闩`的地方，自动停下，等待倒计时
    - 倒计时到0时，门闩解除，线程从等待中被唤醒，继续执行
    ```java
    class Task implements Runnable{
        // 需要在task中定义成员变量
        private final CountDownLatch countDownLatch;
        void run(){
            //就位
            countDownLatch.await(); //在此等待
        }
    }

    // 模拟高并发场景
    mian(){
        // 设置倒计时为1
        CountDownLatch countDownLatch = new CountDownLatch(1);
        // 定义多个线程
        for(...){
            Task task = new Task(countDownLatch);
            Thread t = new Thread(task);
            t.start();// 启动线程，所有线程都会在门闩处等待
        }
        //做点别的
        countDownLatch.countDown(); //手动让倒计时减1
    }
    ```
2. 如果想模拟秒杀一件商品的场景
    ```java
    class Task implements Runnable{
        // 在task类中定义静态boolean类型标记
        private static boolean flg = false;
    }

    main(){
        // 定义静态同步方法
        private static synchronized void onlyOne(){
            if(!flg){
                sout("抢到了")；
                flg = true；
            }
        }
    }
    ```
3. 并行计算（让主线程等待）
    - 一个下载任务， 多个子线程负责下载， 一个主线程负责合并
    - 主线程会等待， 直到所有子线程下载完成
    1. 可以把CountDownLatch的计数器设置为线程数量，没完成一个就减1
    ```java
        class Task implements Runnable{
        // 需要在task中定义成员变量
        private final CountDownLatch countDownLatch;
        void run(){
            //下载任务
            countDownLatch.countDown(); //下载完成后计数器-1
        }
    }

    mian(){
        for(){
            //创建线程执行任务
        }
        countDownLatch.await(); //让主线程等待
        // 执行合并任务
    }
    ```

### 2. CyclicBarrier, 循环屏障
- 可以定义`多个屏障`，线程`多次等待`
- 10名玩家点击匹配后， 才进入选英雄界面； 10名玩家选好英雄后， 才进入游戏加载； 10名玩家全部完成加载后，游戏才开始
- 缺点： 参与者数量不可更改 -》 Phaser 可更改
1. 两种构造器
    1. CyclicBarrier(int parties, Runnable barrierAction)
        - barrierAction, 这是一个任务， 谁最后到达谁执行这个任务
    2. CyclicBarrier(int parties)
2. 游戏的例子
    ```java
    // 可以多次等待
    void run(){
        // 1. 开始匹配, 匹配成功
        cyclicBarrier.await(); //等待其玩家
        
        // 2. 开始选英雄， 选好英雄 
        cyclicBarrier.await(); //等待其玩家
    }

    main(){
        CyclicBarrier cyclicBarrier = new CyclicBarrier(10, new Runnable(){
            @Override
            run(){
                sout("最后一位玩家：" + Thread.currentThread().getName());
            }
        })
        //创建线程执行任务
    }
    ```

### 3. Exchanger， 数据交换器
- 让两个线程实现数据交换， 拷贝一份给对方
- 主要用于数据校验， `比较二者数据是否一致`
    ```java
    void run(){
        String A = "苹果"；
        // 与另一个线程交换，获取对方的数据
        String B = exchanger.exchange(A);
        // 其他对比处理
    }

    main(){
        //创建线程执行任务
    }
    ```

### 4. Semaphore,信号量， 许可证
- 通过给线程发放许可证， 来`限制同一时刻`访问资源的线程数量
- 类似于 办事窗口 数量
1. 构造
    1. int permits， 许可证/窗口 数量
    2. boolean fair， 可选参数
        - 公平： 等待时间长的，优先发放许可证
        - 不公平： 相反
2. 使用
    ```java
    void run(){
        try{
            semaphore.acquire(); //尝试获取许可证
        } finally{
            semaphore.release(); //释放许可证
        }
    }
    ```
