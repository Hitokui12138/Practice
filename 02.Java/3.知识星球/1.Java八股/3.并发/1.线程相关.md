## 1. 概念
### 1.1 进程, 线程, 协程
1. `进程`(车间), 系统`运行程序的基本单位`
    - CPU 密集用多进程
    - 进程是程序的一次执行过程，JVM就是一个进程
2. `线程`(工人), 一个进程包含多个线程, 是`CPU调度的最小单元`
    - 适合IO 密集型任务, `在同一时间需要完成多项任务时`就需要用到线程
    - 多个线程共享进程的堆和方法区资源
    - 每个线程有自己的程序计数器、虚拟机栈和本地方法栈
3. `协程`(任务清单)
    - 适合超高并发
    - 一个工人（线程）可以拿着多个任务清单
    - 执行与否, 顺序, 均由工人控制, 进程 / 线程由操作系统内核调度，协程由用户代码调度（更灵活）。
### 1.2 并行, 并发
- 描述执行多个任务的方式
1. `并行` Parallelism, 多个任务真正`同时执行`(真同时)
    - `必须多核 CPU`, 比如多核计算密集型任务
    - 提高任务执行速度
2. `并发` Concurrency, 多个任务`交替执行`(假同时)
    - `单核 CPU` 即可实现, 比如单线程处理多 IO 请求
    - 提高资源`利用率`
### 1.3 同步,异步
- 描述任务的执行方式和结果获取方式
1. `同步` Synchronous
    - 调用方 必须`等待` 被调用方 完成任务，期间不能做其他事。
2. `异步` Asynchronous
    - 调用方 发起任务后, 不用等待, 可以继续做别的事, 任务完成后通过`回调/事件`获取结果
### 1.4 阻塞（Blocking）vs 非阻塞（Non-blocking）
- 描述程序在等待某个操作完成时的状态, 挂起/非挂起
1. `阻塞` Blocking
    - 一个线程执行时, 其他线程拿不到锁，必须`等待`
    - 阻塞式的解决方案：synchronized，lock
2. `非阻塞` Non-blocking
    - 一个线程执行时, 其他线程拿不到锁, 可以先去做别的
    - 非阻塞式的解决方案：原子变量
3. 同步 / 异步 ≠ 阻塞 / 非阻塞
    1. 同步可以是阻塞（如普通 time.sleep），也可以是非阻塞（如轮询检查任务状态）；
    2. 异步通常是非阻塞的（如 asyncio.sleep）。

## 2. Java的线程
### 2.1 创建线程三种方式
1. 继承Thread类
    1. 重写 void run()方法, 线程启动后自动调用run()方法
    2. myThread.start() //这是一个同步方法, 且只能调用一次
        - 线程多次start()会出问题
2. 实现Runnable接口, 无返回值的任务
    1. 实现run()方法,或者用lambda写
    2. 接口没有启动线程的能力, 因此需要结合Thread使用
        1. new Task()
        2. new Thread(task)
        3. thread.run()
    4. 用`Lambda表达式`简化`匿名内部类`的写法
3. 实现Callable接口, 有返回值的任务
    1. `implements Callable<返回结果类型>`
        1. 实现 T call()方法, 或者用lambda写
    2. 也需要结合Thread使用
        1. new Result()
        2. futureTask = new FutureTask<>(result)
        3. thread = new Thread(futureTask)
        4. thread.run()
    3. 获取返回结果
        - try-catch (InterruptedException, ExecutionException)
            - futureTask.get()
### 2.2 操作线程
1. 获取当前正在执行任务的线程
    - 静态方法: Thread.currentThread()
        - 打印结果: Thread[main, 5, main]
        - 线程名称, 线程优先级, 线程所属线程组名称
2. 获取/设置
    1. getName()/setName()
    2. getPriority()/setPriority()
3. 休眠(隔一秒打印一次)
    - 注意, 这是一个静态方法 `Thread.sleep()`
    - 只能使`当前线程`进入休眠
4. 优雅中断线程
    1. 两个作用
        1. 停止正在运行的线程
        2. 停止休眠的线程
    2. 停止正在运行的线程
        1. 中断线程方法1:
            1. thread.interrupt(), 不能直接中断线程,只是将线程标记为中断状态
            2. 在死循环中调用 while(true){}
                1. 取得当前线程
                2. if(thread.isInterrupted()), 用break结束循环
                    - 这个方法不会清除中断标记
        2. 中断线程方法2:
            1. 不必取得当前线程, 这是一个静态方法
            2. if(Thread.interrupted()), 用break结束循环
                - 这个方法会清除中断标记
5. 让线程放弃执行权?
    1. 让当前线程放弃执行权
        - Thread.yeild()
6. 等待线程死亡?
    - 即让多个线程`按顺序执行`, 等待上一个线程死亡后再执行
    1. 有Task1, Task2, Task2应该依赖Task1
    2. 在Task2的逻辑最上面, task1.join(),如此阻塞task2
7. 希望一个线程在主线程结束后也立即结束
    - 后台线程/守护线程  Daemon Thread
    1. 把一个线程设置为后台线程
        - thread.setDaemon(true)
    2. 线程是否存活?
        - thread.isAlive()
