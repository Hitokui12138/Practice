8. JUC 并发容器
    1.	ConcurrentHashMap	新增	JDK7 分段锁 Segment + ReentrantLock；JDK8 CAS + synchronized + 红黑树；put 流程；size() 计算方式；扩容多线程协同；为什么 key/value 不能为 null
    2.	CopyOnWriteArrayList	新增	写时复制；适合读多写少；add 操作复制整个数组
    3. 	BlockingQueue	新增	ArrayBlockingQueue（有界数组）/ LinkedBlockingQueue（可选有界链表）；put/take 阻塞方法；生产者消费者最佳实践
