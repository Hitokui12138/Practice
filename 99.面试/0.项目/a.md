● 项目名称: 电商网站后端服务系统
● 项目介绍: 面向电商网站的后端服务系统, 覆盖登录鉴权、商品展示、优惠券活动及完整交易链路, 包含下单、库存扣减、订单快照、超时取消与补偿回滚等功能。对外提供标准REST API, 支持前端CMS业务页面与小程序接口调用。
● 涉及技术: Spring Boot, JPA, MySQL, RocketMQ, JWT
● 负责工作: 
  1. 订单核心模块设计与开发
      1. 主导下单流程的事务化实现：基于 Spring 事务管理，在事务内完成库存扣减、订单快照持久化、优惠券核销三大核心操作，确保下单数据一致性与可追溯性；
      2. 针对扣库存、核销券等关键写操作, 设计条件更新与状态校验, 避免重复处理和异常状态流转。
  2. 订单超时取消与补偿链路实现
      1. 设计基于 Redis 键空间通知的订单超时取消机制：下单后推送延迟消息至 Redis，到期触发回调，统一关闭超期未支付订单，降低无效订单占比；
      2. 实现订单取消后的补偿回滚逻辑：基于 Redis 消息可靠性投递，完成库存自动回补、用户优惠券状态回滚，形成 “下单 - 超时 - 取消 - 补偿” 完整交易闭环，保障业务最终一致性。
  3. 参与认证与权限模块的开发
      1. 基于自定义注解+ @Interceptor 实现精细化 API 权限控制：拦截请求解析用户权限，通过 ThreadLocal 注入用户上下文至业务层，解耦鉴权逻辑与业务代码，提升代码可维护性；
      2. 制定统一的异常与响应规范：封装业务错误码枚举类，通过全局异常处理器（@RestControllerAdvice）统一拦截并输出标准化 JSON 响应。
