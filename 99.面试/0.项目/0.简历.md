# 项目1:
● 项目名称：加盟商收益结算平台
● 项目介绍：公司线下业务拓展的核心结算平台，覆盖加盟商入驻申请、签约、日终收益自动精算、月度对账结算与支付的全生命周期管理， 确保资金结算准时、订单可追溯、系统易运营。
● 涉及技术：Spring Batch，Spring Boot, MyBaits, Dubbo（RPC），RocketMQ（事件/定时/异步解耦），Docker / Docker-Compose，AWS（S3 等），Zookeeper（Dubbo 注册中心），分布式任务与批处理。
1. 负责工作:
    1. 批处理与对账精算模块
        1. 负责基于 Spring Batch 的批处理模块开发，通过 RocketMQ 定时/延迟消息触发日终精算，形成稳定的任务调度链路.
        2. 通过 Dubbo 远程调用交易服务与账户服务获取原始数据，完成清洗汇总与核算计算，并输出日/月报结果文件供下游流程使用。
    2. 核心业务 API 与服务开发
        1. 参与基于Spring Boot 构建加盟商管理服务，提供通过REST API支撑加盟商端与运营后台，实现了收益查询、结算明细、入驻审核等核心业务.
        3. 针对高频查询接口进行分页与滚动加载处理，提升查询稳定性与响应速度。
    3. 云平台部署与分布式环境支持
        1. 使用 Docker-Compose 搭建本地分布式联调环境（Dubbo 服务、RocketMQ、ZooKeeper等），提升联调与问题复现效率。
        2. 参与 AWS 测试环境的配置与部署，维护 Zookeeper 注册中心与 RocketMQ 集群接入，保障服务治理与消息链路稳定。

# 项目2
● 项目名称: 云平台Kubernetes环境构建
● 项目介绍: 配合甲方Pega系统版本升级，推进部署流程标准化改造，将原有部署形态迁移至GCP/AWS容器化云平台，提升交付效率、环境一致性与运维可控性，支撑系统平稳升级上线。
● 涉及技术: Google Cloud（GKE/VPC/Firewall/Cloud Armor/DNS），AWS（EKS/VPC/Security Group/NACL/Route53），Docker,  Kubernetes, Helm
● 负责工作: 
  1. Kubernetes 云平台环境交付（GCP/AWS）
      1. 在 GCP 上搭建并配置 GKE 集群（节点池、权限、基础组件等），输出标准化部署与运维操作手册，支持项目交付与后续复用。
      2. 在 AWS 上搭建并配置 EKS 集群（网络、节点、访问控制等），沉淀一致化环境基线与部署规范，保障多环境一致性。
      3. 结合 Helm Chart 形成可重复部署的交付方式，提升部署效率并降低人工差错。
  2. 网络与安全架构设计
      1. 负责设计VPC 与子网划分、路由与访问边界，明确集群内外流量路径与隔离策略。
      2. 负责域名与 DNS 配置管理，打通对外访问与证书/解析策略，确保业务访问链路稳定。
      3. 实现并测试云安全策略：GCP 防火墙与 Cloud Armor、AWS Security Group 与 NACL 的规则设计与测试，满足最小权限与边界防护要求。
  3. 第三方服务部署
      1. 在 GKE/EKS 环境中部署并联调 Pega Constellation，完成关键组件验证与运行稳定性测试。
      2. 负责与 Pega 原厂沟通技术方案与疑难问题定位，推进问题修复与上线节奏对齐。

# 项目3
● 项目名称: 电商网站后端服务系统
● 项目介绍: 面向电商网站的后端服务系统，覆盖登录鉴权、商品展示、优惠券活动及完整交易链路，包含下单、库存扣减、订单快照、超时取消与补偿回滚等功能。对外提供标准REST API，支持前端CMS业务页面与小程序接口调用。
● 涉及技术: Spring Boot, JPA，MySQL，RocketMQ, JWT
● 负责工作: 
  1. 订单模块开发
      1. 负责下单核心流程实现：在事务内完成库存扣减、订单快照持久化与优惠券核销，保证下单数据一致性与可追溯性。
      2. 开发订单查询接口，支持列表、详情查询及按状态分页检索，通过VO/分页模型统一返回格式。
      3. 针对扣库存、核销券等关键写操作，设计条件更新与状态校验，避免重复处理和异常状态流转。
  2. 订单超时取消与补偿链路实现
      1. 设计订单超时取消机制，下单后发送Redis延迟消息，到期后触发键空间通知，统一关闭未支付订单。
      2. 实现取消后的补偿回滚：订单取消后回补库存、回滚用户优惠券状态，形成交易闭环，保障业务一致性。
  3. 参与认证与权限模块的开发
      1. 基于@ScopeLevel+Interceptor实现API权限控制，通过ThreadLocal注入用户上下文，降低业务层与鉴权逻辑耦合。
      2. 制定统一异常与响应规范，映射业务错误码与HTTP状态，通过全局异常处理输出标准响应，提升接口一致性与排障效率。

      2. 负责会计凭证列表等业务页面开发与样式实现（Pega UI + CSS），提升页面可用性与业务操作效率。
