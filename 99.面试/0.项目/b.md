Java开发工程师

电商网站后端服务系统
● 项目介绍: 面向电商网站的后端服务系统，覆盖登录鉴权、商品展示、优惠券活动与完整交易链路（下单、库存扣减、订单快照、超时取消与补偿回滚），对外提供标准 REST API，支持前端业务页面与小程序接口调用。
● 涉及技术: Spring Boot, JPA，MySQL，RocketMQ, JWT
● 负责工作: 
  1. 负责订单模块的开发
      1. 负责下单核心流程实现：在事务内完成库存扣减、订单快照持久化与优惠券核销，保证下单数据一致性与可追溯性。
      2. 完成订单查询接口：支持订单列表/详情查询与按状态分页检索（如待支付、已支付、已取消等），并通过 VO/分页模型统一返回结构。
      3. 关键写操作加入幂等与并发保护：围绕扣库存、核销券、状态迁移等操作设计条件更新与状态校验，避免重复处理与异常状态流转。
  2. 实现订单超时取消与补偿链路
      1. 设计并实现订单超时取消机制：下单后发送 RocketMQ 延迟消息，到期触发取消逻辑，统一处理未支付订单的超时关闭。
      2. 实现取消后的补偿回滚：订单取消后回补库存、回滚用户优惠券状态，形成交易闭环，保障业务一致性。
  3. 参与认证与权限模块的开发
      1. 基于 @ScopeLevel + Interceptor 实现 API 权限控制，并通过 ThreadLocal 注入用户上下文，降低业务层与鉴权逻辑耦合。
      2. 建立统一异常与响应规范：定义业务错误码与 HTTP 状态映射，使用全局异常处理输出统一响应结构，提升接口一致性与排障效率。
