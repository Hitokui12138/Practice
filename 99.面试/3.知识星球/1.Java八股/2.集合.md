# Java集合
1. Collection (单一元素)
    1. List (有顺序)
        1. ArrayList, 非线程安全
            - 查询快、增删慢
        2. LinkedList, 非线程安全
            - 查询慢、增删快
        3. Vector (已被替代)
        4. `CopyOnWriteArrayList`, 线程安全
            - 查询快、增删慢
    2. Set (不重复)
        1. HashSet, 非线程安全
            - 无序、不可重复
        2. LinkedHashSet, 非线程安全
            - 有序（插入顺序）、不可重复
        3. TreeSet, 非线程安全
            - 可排序, 不可重复
        4. `CopyOnWriteArraySet`, 线程安全
            - 无序、不可重复
    3. Queue (不怎么用)
2. Map (键值对)
    1. HashMap, 非线程安全
        - 键无序、键唯一
    2. LinkedHashMap, 非线程安全
        - 键有序（插入顺序 / 访问顺序）、键唯一
    3. TreeMap, 非线程安全, 且Value不为null
        - 键可排序（自然排序 / 自定义排序）、键唯一
    4. HashTable (已被替代)
    5. `ConcurrentHashMap`, 线程安全, 且Value不为null
        - 键无序、键唯一

## 常用方法
1. 集合判空
    - 使用 isEmpty() 方法，而不是 size()==0 的方式。
2. 集合转Map
    - toMap() 方法转为 Map 集合时，一定要注意当 value 为 null 时会抛 NPE 异常。
3. 集合删改
    1. 不要在 foreach 循环里进行元素的 remove/add 操作。remove 元素请使用 Iterator 方式，如果并发操作，需要对 Iterator 对象加锁。
    2. Java8提供一个新方法: list.removeIf(filter -> filter % 2 == 0);
4. 集合去重
    1. 可以利用 Set 元素唯一的特性，可以快速对一个集合进行去重操作，避免使用 List 的 contains() 进行遍历去重或者判断包含操作。
5. 集合转数组, 数组转集合
    1. list.toArray(new String[list.size()]);
    2. Arrays.asList(arr);
