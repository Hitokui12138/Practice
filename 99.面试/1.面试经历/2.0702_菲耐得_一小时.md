1. Java 基础与 JVM 能力
    - 精通 Java 基础，熟练运用 JDK8 核心新特性：Lambda 表达式、Stream 流、Optional 空安全处理、函数式接口等；掌握 JVM 底层基础，包含 JVM 内存模型、垃圾回收机制原理。
2. Spring Boot 框架能力
    - 熟练掌握 Spring Boot，可独立完成项目架构搭建；理解 Spring Boot 自动装配原理、starter 启动器依赖机制。
3. Spring 生态全家桶应用
    - 熟悉 Spring 体系技术栈：Spring MVC、Spring MyBatis/MyBatis-Plus、Spring 事务；可落地解决业务场景下事务管控、数据持久化落地问题。
4. 关系型数据库能力
    - 精通 MySQL、Oracle 等关系数据库，能编写高性能 SQL；掌握索引优化、分库分表基础方案，理解数据库事务隔离级别、行锁 / 表锁等锁机制。
5. 主流中间件实战能力
    - 熟练 Redis：缓存架构设计、分布式锁落地；熟练 RabbitMQ/Kafka：消息队列场景选型、消息可靠性投递与补偿方案，可结合业务完成中间件落地开发。
6. 工程化工具
    - 熟练使用 Git 版本控制、Maven 项目构建管理工具。
7. 加分技能项
    - 前端：Vue、Angular 框架；
8. 总结
    1. 硬性必备项（必考核）：Java8、JVM、SpringBoot、MyBatis、MySQL 优化、Redis、MQ、Git/Maven
    2. 进阶考核项：分布式锁、消息可靠性、分库分表、事务机制、高并发优化
    3. 优先加分项：前端框架、APP 对接、高可用架构、保险行业背景（面试优先级大幅提升）
