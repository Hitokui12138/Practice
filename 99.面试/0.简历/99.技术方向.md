1. 分布式 / 中间件必加细节（面试官高频提问点）
Redis：缓存策略（LRU/TTL）、缓存三大问题（穿透 / 击穿 / 雪崩）解决方案、数据结构使用场景、持久化配置
RabbitMQ：交换机类型、ACK 机制、死信 / 延迟队列、消息重试、幂等、堆积处理、集群模式
Dubbo：注册中心、负载均衡、容错策略（重试 / 熔断 / 降级）、序列化方式、超时配置
MySQL：索引设计、慢查询优化、事务隔离级别、锁机制、分库分表（如有）
ES：分词器、索引设计、DSL 优化、分页方案、集群运维
2. 金融 / 结算类系统（重点加：合规、数据安全、幂等、对账）
这类业务对数据准确性要求极高，一定要写：
数据对账、日终 / 月末结算规则
数据备份、日志留存、合规审计
防篡改、幂等、分布式事务方案
3. 支付类系统（重点加：安全、签名、回调、资金规则）
签名验证、证书使用、IP 白名单
回调幂等、状态机流转
分账、退款、资金风控规则
