# 统计SpringBoot各个API的耗时
1. 最简单：SpringBoot 自带拦截器（0 依赖）
    - 自己写个拦截器，所有接口自动打印耗时。
    - 不用装任何东西，直接看控制台，知道哪个接口慢。
2. `Spring Boot Actuator`（官方监控）
    1. 引入依赖
    2. 配置打开监控
        ```yaml
        management:
            endpoints:
                web:
                exposure:
                    include: "*"
        ```
    3. 通过下面地址查看监控数据
        - http://localhost:8080/actuator/metrics/http.server.requests
    4. 能看到
        - 平均响应时间
        - 最大响应时间
        - 调用次数
        - 异常次数
3. 可视化神器：Micrometer + Prometheus + Grafana 这是互联网公司标配。
    - 专业级监控面板，实时看接口速度曲线。
    - 你能看到：
        1. 每个接口 QPS
        2. 95 线、99 线响应时间（最关键！）
        3. 慢接口排行
        4. 接口耗时趋势图



# 压力测试(模拟100个人访问接口)
1. JMeter —— 老牌、稳定
    - apifox底层就是JMeter
        - 用 Actuator 看线上哪些接口慢。
        - 用 Apifox 对这些慢接口做单测 + 压测，验证优化效果。
    先在 Apifox 把所有核心接口（首页、帖子、评论、用户）都导入。
        - Apifox 完美支持 Swagger（OpenAPI 2.0/3.0）导入
    跑一遍自动化场景，导出报告，标记出耗时 > 300ms 的接口。
    优化后再跑一次，对比耗时变化，确认优化有效。
2. ApiPost / Postman —— 简单压测
3. WRK —— 命令行极快压测
