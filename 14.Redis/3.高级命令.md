# 频道与订阅
1. 订阅一个频道
    - SUBSCRIBE testChannel
        - 之后CLI就阻塞了, 一直监听这个频道
2. 打开另一个CLI, 发布信息
    - PUBLISH testChannel message1
        - 这样第一个终端就能收到消息了
        - 订阅者可以有多个
3. 缺点在于, messsage无法持久化, 无法记录历史等等
    - 可以用Stream来解决这些问题

# Stream 消息队列
- 命令都以X开头
1. 添加创建
    1. XADD testStream * K V
        - * 表示自动生成一个ID, 会自动递增
        - 回显信息就是ID
    2. XADD testStream 1-0 K V 
        - 注意格式`整数-整数`
            - 第一个整数表示时间戳, 需要手动保持递增
            - 第二个表示序列号
2. 查询
    - XLEN testStream, 查询数量
    - XRANGE testStream - + , 表示查询所有信息
    - XDEL testStream ID , 按照ID删除消息
    - XTRIM testStream MAXLEN 0 ,  删除所有
3. 类似订阅的功能
    - XREAD COUNT 2 BLOCK 100000 STREAMS testStream 5
        - 若没收到消息则阻塞(等待)10秒
    - 然后在另一个终端 XADD testStream 2-0 K V , 这样就能收到了
4. 消费者组
    1. 创建
        - XGROUP CREATE testStream testGroup 0
        - 最后那个0是id
    2. 查看消费者组的信息
        - XINFO GROUPS testStream
    3. 添加消费者
        - XGROUP CREATECONSUMER testStream testGroup testConsumer
    4. 让消费者消费两条信息
        - XREADGROUP GROUP testGroup testConsumer COUNT 2 BLOCK 10000 STREAMS testStream

## Geospatial 存储地理信息
## HyperLogLog
- 一种用来对基数进行统计的算法
## Bitmap 位图
- 字符串的拓展, 支持一些位运算, 可以用来记录签到情况, 点赞数等等
## Bitfield
- 可以用来记录用户的一些基本信息, 等级, 是否在线
