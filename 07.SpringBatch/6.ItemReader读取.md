# ItemReader读取文件
1. 纯文本平面文件
    1. SpringBatch默认使用`FlatFileItemReader`这个类
        1. 主要适用`readLine（）`这个方法
        2. 或者`BufferReader()`
    2. 方式1: delimited--字符串截取， 自动封装
        - 比如读取csv文件，然后把每行数据封装成对象
        - 适合一一对应的数据
        ```java
        public FlatFileItemReader<User> itemReader(){
            // 设置文件，解析数据， 封装数据
            return new FlatFileItemReaderBuilder<User>()
                        .name("userItemReader")
                        .resouce(new ClassPathResouce("xxx.txt")) //获得文件
                        .delimited().delimiter(",") //分割数据
                        .names("id","name","age")
                        .targetType(User.class) //封装数据
                        .build();
        }
        ```
    3. 方式2: FieldSetMapper--字符串的映射，手动封装
2. JSON格式
    - JSONItemReader
3. 读数据库
    1. 游标
    2. 分页
