# ItemReader输出
1. 输出纯文本平面文件
    1. SpringBatch默认使用`FlatFileItemWriter`这个类
        ```java
        public FlatFileItemWriter<O> itemWriter(){
            return new FlatFileItemWriterBuilder<O>
                        .name("xxxwriter")
                        .resouce(new PathResouce("C:/output")) //输出位置
                        .formatted().format("id: %s,name: %s") //输出格式
                        .names("id", "name") //解释上面的%
                        .build()
        }
        ```
