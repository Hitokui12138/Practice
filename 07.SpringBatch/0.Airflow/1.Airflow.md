# Airflow 与 MWAA
- AWS MWAA 是 AWS 托管版 Airflow 云服务，MWAA 底层完全基于原生 Airflow，只是由 AWS 托管运维、扩容、安全、底层基础设施。
1. 自建 Airflow：
    - 要维护 7 大组件：Web 服务、调度器、Worker 集群、元数据库、Redis/RabbitMQ、反向代理、监控告警；版本升级需要停机迁移元数据、兼容测试，故障排查全靠运维。
2. 使用MWAA：
    - 用户仅负责：`编写 DAG`、上传依赖包、配置 IAM 角色、查看任务执行状态；AWS 负责硬件宕机恢复、Airflow 版本平滑升级、数据库备份、安全漏洞修复。

## DAG （DAG = Directed Acyclic Graph）有向无环图
- 有向： 任务有先后执行顺序，A 做完才能跑 B
- 无环： 绝对不能出现循环依赖（A→B→C→A）

## 用DAG控制SpringBatch的执行
- MWAA 不能直接上传、运行 JAR，禁止用 BashOperator 本地 java -jar
- HTTP 接口触发 SpringBatch + HttpSensor 轮询状态

```python
# 触发 Job → 取出执行 ID → 循环轮询状态 → 成功结束，失败重试告警
from datetime import datetime, timedelta
from airflow import DAG
from airflow.providers.http.operators.http import SimpleHttpOperator
from airflow.sensors.http_sensor import HttpSensor
from airflow.utils.dates import days_ago

default_args = {
    "owner": "data-team",
    "start_date": datetime(2026, 1, 1),
    "retries": 2,
    "retry_delay": timedelta(minutes=3),
    "catchup": False
}

with DAG(
    dag_id="mwaa_run_spring_batch_datasync",
    default_args=default_args,
    schedule_interval="0 4 * * *",  # 每日凌晨4点调度
    tags=["springbatch", "mwaa", "etl"]
) as dag:

    # 1. 调用接口启动SpringBatch Job
    trigger_batch = SimpleHttpOperator(
        task_id="trigger_spring_batch_job",
        http_conn_id="spring_batch_vpc_api",
        endpoint="/batch/api/start?jobName=dataSyncJob",
        method="POST",
        response_filter=lambda response: response.json(),  # 解析JSON
        log_response=True
    )

    # 2. 轮询等待任务执行完成，从上游XCom拿到execId
    wait_batch_complete = HttpSensor(
        task_id="wait_batch_job_finish",
        http_conn_id="spring_batch_vpc_api",
        endpoint="/batch/api/status/{{ ti.xcom_pull(task_ids='trigger_spring_batch_job')['execId'] }}",
        # 判定条件：状态为COMPLETED才算成功
        response_check=lambda resp: resp.json()["jobStatus"] == "COMPLETED",
        poke_interval=15,  # 每15秒轮询一次
        timeout=3600 * 2,  # 最长等待2小时，超时判定失败
        mode="poke"
    )

    # 任务依赖：先启动，再等待完成
    trigger_batch >> wait_batch_complete
```

## 一个ABC的例子
```python
from datetime import datetime, timedelta
from airflow import DAG
from airflow.providers.http.operators.http import SimpleHttpOperator
from airflow.sensors.http_sensor import HttpSensor

default_args = {
    "owner": "batch",
    "start_date": datetime(2026, 1, 1),
    "retries": 3, # 最大重试3次
    "retry_delay": timedelta(minutes=2), # 失败后间隔2分钟重试
    "catchup": False
}

with DAG(
    dag_id="batch_abc_serial_pipeline",
    schedule_interval="0 5 * * *",
    default_args=default_args,
    tags=["springbatch", "A-B-C串行"]
) as dag:

    # ========== Job A ==========
    trigger_A = SimpleHttpOperator(
        task_id="trigger_A",
        http_conn_id="spring_batch_vpc_api",
        endpoint="/batch/api/start?jobName=jobA",
        method="POST",
        response_filter=lambda r: r.json(),
        log_response=True
    )

    wait_A = HttpSensor(
        task_id="wait_A_complete",
        http_conn_id="spring_batch_vpc_api",
        endpoint="/batch/api/status/{{ ti.xcom_pull('trigger_A')['execId'] }}",
        response_check=lambda resp: resp.json()["jobStatus"] == "COMPLETED",
        poke_interval=10,
        timeout=7200
    )

    # ========== Job B ==========
    trigger_B = SimpleHttpOperator(
        task_id="trigger_B",
        http_conn_id="spring_batch_vpc_api",
        endpoint="/batch/api/start?jobName=jobB",
        method="POST",
        response_filter=lambda r: r.json(),
        log_response=True
    )

    wait_B = HttpSensor(
        task_id="wait_B_complete",
        http_conn_id="spring_batch_vpc_api",
        endpoint="/batch/api/status/{{ ti.xcom_pull('trigger_B')['execId'] }}",
        response_check=lambda resp: resp.json()["jobStatus"] == "COMPLETED",
        poke_interval=10,
        timeout=7200
    )

    # ========== Job C ==========
    trigger_C = SimpleHttpOperator(
        task_id="trigger_C",
        http_conn_id="spring_batch_vpc_api",
        endpoint="/batch/api/start?jobName=jobC",
        method="POST",
        response_filter=lambda r: r.json(),
        log_response=True
    )

    wait_C = HttpSensor(
        task_id="wait_C_complete",
        http_conn_id="spring_batch_vpc_api",
        endpoint="/batch/api/status/{{ ti.xcom_pull('trigger_C')['execId'] }}",
        response_check=lambda resp: resp.json()["jobStatus"] == "COMPLETED",
        poke_interval=10,
        timeout=7200
    )

    # 关键串行依赖：A启动→A等待完成 → B启动→B等待完成 → C启动→C等待完成
    trigger_A >> wait_A >> trigger_B >> wait_B >> trigger_C >> wait_C
```

## 重试后还是失败的话
- MWAA 绑定 CloudWatch 告警，监控 DAG 失败指标
- MWAA WebUI 找到job_A_group → 点击 Clear 清除状态 → DAG 会重新调度执行 A，链路恢复。
