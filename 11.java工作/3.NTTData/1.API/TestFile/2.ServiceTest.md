## ServiceTest
1. 注解
    ```java
    @SpringBootTest
    @TestPropertySource(properties = {...})
    @AutoConfigureMockMvc //启动mockito
    class XXServiceTest extends BaseTests{...}
    ```
2. 成员变量
    ```java
    @InjectMocks//标记这是一个待测试类,会自动注入它的依赖项@Mock或@Spy
    @Autowrired
    private XXService service;

    @SpyBean //@Spy是原生注解,这个是SpringMVC提供的
    XXDao dao;

    @SpyBean //其他类,比如采番类之类的
    OtherService otherService;

    //@BeforeEach初始化InDto
    @BeforeEach

    //有外部类时需要重制mock
    @AfterEach
    public void afterEach(){
        reset(otherService);
        s3Del("xxx");
    }
    ```
3. 正常终了
    ```java
    /**
     * 正常测试一般由InDto控制不同的测试种类
     */
    @ParameterizedTest(name="{0} caseMethodName={1}")//单独测试的名称
    @Display("正常终了")//测试集的名称
    @CsvSource({//把一个测试分成多次
        "测试1,test001-1",
        "测试2,test001-2"
    })
    void test001(String name, String caseMethodname){
        //1. 采番
        doReturn("10001").when(otherService).XXX(any());
        //2. 运行
        try{
            service.execute(InDto);
        }catch(Exception e){
            fail();//若执行时出现异常,则视为测试失败
        }
    }
    ```
4. 异常终了
    ```java

        // 2.
    ```
