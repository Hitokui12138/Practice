2. 所有Test方法的前处理 
    1. 读取json文件作为输入数据,`初始化json`
    2. 读取前后sql文件进行数据库初始化和删除
    3. 检查s3Path下面有没有文件,有的话删除干净
    ```java
    /**
     * dataSource 表示测试环境数据库
     */
    @BeforeEach
    public voud baseBeforeEach(
        @Qualifer("dataSource") javax.sql.DataSource dataSource,
        juniter.api.TestInfo info
    ){
        //  1. 读取JSON输入数据
        //  1.0 通过info获取测试类的路径
        String path = info.getTestClass()....replace(",","/");
        String testName = getTestName(info);
        //  1.1 文件路径 使用join添加一个/
        String inputDataPath = String.join("/", path, testName, "inputData.json")
        //  1.2 inputData.json 读入到jsonNode中
        classPathResource = new ClassPathResource(inputDataPath).getFile();
        jsonNode = objectMapper.readTree(classPathResource);

        // 2. SQL初期处理
        String initSqlPath = String.join("/", path, testName, "exeSql_before.sql")
        //  2.1. 创建一个ResourceDatabasePopulator
        populartor = new ResourceDatabasePopulator();
        populator.addScript(new ClassPathResource(sqlPath))
        //  2.2. 执行sql
        populator.execute(dataSource);//在测试环境数据库中执行

        //  清空S3临时文件夹
        if(Files.exists(tmpDirPath)){
            this.deleteAll(tmpDirPath);
            Files.createDirectories(temDirPath);
        }
    }
    ```
3. 所有测试的后处理
    1. @AfterEach
    2. 终了sql
    3. 删除S3临时文件
        - this.deleteAll(tmpDirPath);
    ```java
    @AfterEach
    public voud baseAfterEach(
        @Qualifer("dataSource") javax.sql.DataSource dataSource,
        TestInfo info
    ){
    ```
