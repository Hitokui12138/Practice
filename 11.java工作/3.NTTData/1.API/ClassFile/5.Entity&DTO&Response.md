# Entity&DTO
## Entity
1. 注解
    1. lombok @Data
2. 父类
    1. implements Serializable
        - 在哪里用的?
3. 如何Map(注意包不要导错了)
    1. Varchar -> String
    2. 日付 -> LocalDate
    3. Number -> Long
    4. 日時 -> LocalDateTime
    5. 浮点数 -> BigDecimal

```java
@Data
public class XXXEntity implements Serializable{
    private String xxxNumber;
}
```

## DTO
1. DTO分类
    1. 需要验证
        - xxxHeaderDto, ParamDto
    2. 不需要验证 和Entity一样使用@Data即可
        - ServiceInDto
2. 需要验证的DTO
    ```java
    @Data
    public class XXXHeaderDto implements Serializeble{
        //TRACE ID
        @NotEmpty
        @UUIDFormat
        private Strinf traceId;

        //处理日期时间
        @NotEmpty
        @DayFormat(...)
        @DayExists(...)
        private String processingDate;

        @NotEmpty(groups = {FirstGroup.class})//GROUP
        @StrDigits(size = 10)
        private String xxxNumebr;
    }
    ```

## Response @Data
- 返回前端的数据必须序列化, @Data可以帮忙序列化
1. JsonResponse
    - traceId, processingDate
2. WarnResponse extends JsonResponse
    - 再审查号码
    - Message
3. ErrorResponse
    - errorCode, errorMessage
    - traceId, processingDate
