## Validator
1. Structure
    - StrDigits.java

2. StrDigits.java
    ```java
    @Documented
    @Constrain(validatedBy = {StrDigitsValidator.java})
    @Target({METHOD, FIELD, ANNOTATION_TYPE, CONSTRUCTOR, PARAMETER})
    @Retention(RUNTIME)
    @Repeatable(com.xxx.validation.StrDigits.List.class)
    public @interface StrDigits {
        String message() default "{jakarta.validation.constrains.StrDigits.message}";
        // 参数
        int size();

        Class<?>[] groups() default {};
        Class<? extends Payload>[] payload() default {};

        @Target({METHOD, FIELD, ANNOTATION_TYPE, CONSTRUCTOR, PARAMETER})
        @Retention(RUNTIME)
        @Documented
        public @interface List{
            StrDigits[] value();
        }
    }
    ```
3. StrDigitsValidator.java
    ```java
    public class StrDigitsValidator 
      implements ConstraintValidator<StrDigits, String>{
        private int size;
        @Override
        public void initialize(StrDigits strDigits){
            size = strDigits.size()
        }
        @Override
        public boolean isValid(String value, ConstraintValidatorContext context){
            // 没有输入则不要check
            if(!StringUtils.hasLength(value)){
                return true;
            }
            // 检查位数
            return value.length() == size;
        }
    }
    ```
