# 准备
1. 需要JUnit和Mockito依赖
    - Maven中央仓库:https://search.maven.org/?eh=
    1. Mockito 4.3.1
    2. JUnit 5.8.2
2. 为什么要用Mock
    1. Mock可以看作是创建了一个虚拟的对象,在测试环境中替换掉真实的对象
        - 防止影响真实的数据库
        1. 可以验证该对象的某些方法的调用情况
            - 调用了多少次
            - 参数是什么
        2. 重新定义该对象的行为
            - 指定返回结果
            - 指定特定动作
# 具体使用
1. mock方法
    - 来自org.mockito.Mock
    - public static <T> T mock(Class<T> classToMock)
2. 定义对象的行为(打桩)
    - 使用Mockito.when(r.func())
    - 然后 .thenXXX()
        1. thenReturn()
        2. thenThrow()
        3. thenCallRealMethod()//调用原来的方法
3. 验证和断言
    1. 验证该对象是否发生过某些行为 verify()
        1. 配合times()方法验证执行次数
    2. 断言,使用Assertions提供的方法
        1. assertEquals(excepect, target)
            - `前面`是期待值
        2. assertTrue()
```java
@Test
void Test1(){
    //1. 用mock方法创建Random对象
    Random r = Mockito.mock(Random.class);
    sout(r.nextInt());//执行一个方法,如果没有定义行为,则一直是返回对象的默认值

    //2. 打桩
    Mockito.when(r.nextInt()).thenReturn(100);

    //3.1 判断该对象没有执行某个方法
    Mockito.verify(r).nextInt();//测试时不会发生异常
    Mockito.verify(r, Mockito.times(1)).nextInt();//验证执行次数

    //3.2 断言结果
    Assertions.assertEquals(100, r.nextInt());
}
```

# 用注解
1. 直接用`@Mcok`标记需要mock的对象
2. 使用`MockitoAnnotations.openMocks(this);`来启动
    - 之前是initMocks()
3. 使用`@InjectMocks`,给所有对象注入@Mock
```java
class Test{
    //1. 标记需要mock的对象
    @Mock
    private Random r;

    @BeforeEach
    void init(){
        //2. 启动mock
        MockitoAnnotations.openMocks(this);
    }
}
```
# Spy与Mock
1. spy()与mock()的区别
    1. 被spy()的对象仍会运行真实方法
    2. spy()方法的参数是对象实例,而mock()是class
```java
class Test{
    //@Mock
    @Spy
    private Random r;

    @BeforeEach
    void init(){
        //2. 启动mock
        MockitoAnnotations.openMocks(this);
    }
}
```
