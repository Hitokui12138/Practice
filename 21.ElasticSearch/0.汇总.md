1. ES 是一个`分布式 搜索和分析 引擎`
    - 分布式架构: 数据自动分片 shard
    - Restful: 所有操作通过HTTP API完成
    - JSON文档存储: 数据以JSON格式存储
    - ELK技术栈: ES + Logstash(数据读取, 清洗) + Kibana(可视化)

2. 核心概念
    1. 索引Index, 就是数据库/一张表, 存放同一类文档的容器
        - product_index
    2. 文档Document, 就是一条数据, 有唯一_id
    3. 映射Mapping, 描述文档有哪些字段, 分别是什么类型
        - type, 字段数据类型
        - index, 是否创建索引, 默认为true
        - analyzer, 分词器
        - properties, 该字段的子字段
    4. 分片(Shard), 一个索引会被查分成多个子集, 用于分布式存储
    5. 副本(Replica), 用于保证高可用性和负载均衡
    6. 倒排索引(Invert Index), 通过一个单词, 获取文档ID, 实现高速搜索
        - 比如搜索“手机”, 返回所有含该词的文档

3. SpringBoot中使用ES
    1. RestHighLevelClient, 主要用于6.x和7.x版本
        1. 引入依赖, 配置es
        2. ES配置类, ElasticSearchConfig
        3. 做一个ES工具类对常用操作进行封装
            - 全局搜索
            - 分组统计
            - 分页查询
            - 创建文档, 批量更新文档
    2. ElasticSearch Java API Client, 主要用于8.x版本, 完全替代了RestHighLevelClient
