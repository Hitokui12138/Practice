# 用docker安装ES和kibana
- 两者版本号需要一致
- kibana:9.4.1 elasticsearch:9.4.1
- 用docker-compose启动
1. 检查ES
    -  http://localhost:9200
    - 输出JS则表示没问题
2. 检查Kibana
    -  http://localhost:5601
# kibana
1. 主要使用 dev-tools 和 Index Management

# ES默认的分词器对中文效果不好, 下载 IK分词器
1. 在github上找到对应版本
    - https://release.infinilabs.com/analysis-ik/stable/
2. 进入ES容器内部
    - docker exec -it 容器号 bash
    - 进入bin目录, 里面有一个plugin文件
    - ./elasticsearch-plugin install https://
3. 注意这里是直接进容器安装的, 把容器down了之后就没了
