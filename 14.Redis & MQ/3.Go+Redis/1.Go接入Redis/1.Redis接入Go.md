# Go连接Redis
1. 初始化项目
    - go mod init redis-learn
2. 安装客户端
    - go get github.com/redis/go-redis/v9
3. 创建一个utils包, 然后给所有项目提供一个`单例的`RedisClient实例
## Go的单例模式的实现
1. `var()` 是 Go 语言中批量声明变量的简写语法，本质上`和单独写 var 变量名 类型 是等价的`，只是把多个变量声明整合到一个 () 中，让代码更整洁、可读性更高。
1. `sync.Once`是 Go 实现并发安全单例的首选方式，比手动加锁更简洁、更高效。
    - 核心功能是保证传入的函数只会被执行一次，即使在多协程（并发）场景下也能保证
    1. 然后使用下面这种方法调用
        - `once.Do(func() {...})`
```go
// 确保整个程序运行期间，redisClient（Redis 客户端实例）只会被初始化一次
var (
	redisClient *redis.Client
	once        sync.Once 
)

func GetRedisClient() *redis.Client {
	// 使用 sync.Once 来确保 Redis 客户端实例只会被初始化一次
	once.Do(func() {
		// 初始化 Redis 客户端实例
		redisClient = redis.NewClient(&redis.Options{
			Addr:         "localhost:6381", // Redis 服务器地址
			DB:           0,                // 使用默认数据库
			PoolSize:     10,
			PoolTimeout:  10,
			MinIdleConns: 1,
		})
	})
	return redisClient
}
```
