## 一. Redis的String SDS结构
0. Redis的String的主要作用
    1. 缓存数据
    2. 计数器
    3. 状态标记
    4. 分布式锁
1. Redis, Go, Java
    1. Redis的String的本质是`二进制安全的字节数组`
        - 可变的, 支持原子操作
    2. Go的string是go的基础数据类型, 是`不可变的`UTF-8 编码字节序列
        - 任何修改都会生成新字符串
        - 需要通过 strings 包操作, 或者转换成[]byte再操作
    3. Java的String是引用类型, 底层是`不可变的`char[] 或者 byte[](java9+) 
        - 任何修改都会生成新字符串
        - 引用类型自带很多方法, 但批量修改推荐使用StringBuilder（非线程安全）/StringBuffer（线程安全）
2. Redis的String可以存很多东西 
    1. JSON, 序列化内容
    2. 图片二进制码,不要超过1M
    3. protobuf, 你可以把它理解成一种「数据格式规范」+「配套工具」，就像 JSON/XML 一样用于数据传输 / 存储，但性能和效率远高于二者；
3. Redis的String的实现 SDS (Simple Dynamic String)
    ```c
    struct SDS{
        len //当前长度
        alloc //已分配空间(能容纳的长度)
        buf[] //数据
    }
    ```
    1. 优势:
        1. 获取长度 O(1)
        2. 自动扩容 (小于44字节一次分配)
        3. 二进制安全 允许 \0 存在
        4. 减少内存拷贝
    2. 关于buf[], Redis会自动选择合适的编码方式
        1. 整数编码: 数字, Redis 的整数是 64 位有符号整数
        2. embstr: 短字符串, 嵌入字符串, 小于44字节
        3. raw编码: 长字符串
## 二. String的INCR方法
- INCR 是 Redis 提供的`原子性自增命令`，全称 "Increment"
- 作用: 对指定的 Redis String 类型键的值执行加 1 操作，返回自增后的结果。
- 对象: 但值必须是`整数格式`的字符串
    1. 这个功能非常常用
        1. 原子性
            - 尤其用于`统计商品销量`, 即使同时海量用户下单, 数量也不会错
                - INCR 把 “读取 - 计算 - 写入” 封装成一个原子操作，从根本上避免这个问题
    2. `INCR key`, 也可以用于新建key, 值从1开始
## 三. Redis的缓存模式
1. Cache模式
    1. 先查Redis
        1. 命中则返回
        2. 没有则去查数据库
    2. 但是这种模式必须设置过期时间
        1. 内存持续增长, 冷数据占空间
        2. 数据可能过期
    3. 常用设置方法
        1. `SET k v EX 10`, 设置的同时设置过期时间
        2. `EXPIRE k 180`, 给没有过期时间的设置过期时间
        3. `TTL k`, 查看Key的剩余过期时间
            - `-1`, 没有设置过期时间
            - `-2`, 已经过期

## 四. 实战
1. 需求
    1. 实现一个文章阅读计数器
        - 要求阅读量统计, 高并发安全, 自动过期
2. `ctx := context.Background()`
    1. context 包提供的核心函数，返回一个「空的、不可取消的、无截止时间的」基础上下文实例。
    2. 用于在 goroutine（协程）之间传递「控制信号」 的工具, 比如
        1. `取消操作`（比如请求超时后取消后续逻辑）
        2. 传递截止时间 / `超时时间`；
        3. 传递少量共享数据（如请求 ID、用户 Token）；
        4. 控制协程的生命周期（避免协程泄露）。
    3. 这行代码几乎出现在所有使用 `Go 第三方库`（如 Redis、gRPC、HTTP 客户端）的场景中，因为这些库的核心方法都要求传入 context.Context 参数
3. 自增 INCR
    - val, err := client.Incr(ctx, key).Result()
4. 获取 GET
    - val, err := client.Get(ctx, key).Int64()
