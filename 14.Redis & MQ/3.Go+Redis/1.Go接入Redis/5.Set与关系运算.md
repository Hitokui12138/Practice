# Set类型
## 一. Redis的Set
1. `无序, 不可重复的集合`
    1. 自动去重
    2. 高效判断一个东西是否存在
    3. 集合计算
2. 典型用途
    1. 标签系统, 利用Redis的Set做倒排序
    2. 好友关系, 哪些好友是我们共有的
    3. 关注列表, 抽奖去重, 权限集合 主要使用去重功能
3. Redis的Set有两种结构
    1. `intset`, 字段数超 512 后自动变成hashtable
        - 连续数组,极低内存, 无hash开销
    2. `hashtable`, 和Hash相同
        1. Hash使用hashtable是为了实现键值对
            - 键是 Hash 的 field，值是 Hash 的 value
        2. Set为了`去重`,只使用hashtable的`Key`, Value固定设置为null
