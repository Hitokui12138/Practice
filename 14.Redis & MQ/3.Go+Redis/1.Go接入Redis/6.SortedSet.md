# Sorted Set与排行榜设计
## 一. Sorted Set
- 可排序的唯一集合
- 排行榜, 热度榜, 延迟队列,优先级任务, 时间线排序
1. SortedSet也是双结构
    - dict + skiplist(字典 + 跳表)
    1. dict结构
        - 通过merber成员可以找到score分数
    2. skiplist `跳表原理`
        - 一种有多层索引的链表
        1. 最高索引: Head -> 9 -> nil
        2. Head -> 5 -> 9 -> 13 -> nil
        3. ...
        4. 数据层: Head -> 1 -> 2 -> 3 ... -> 16 -> nil
    3. skiplist从最上层的索引层开始找, 如果没找到索引, 就往下一层
        - 复杂度平均为 O(logN), 最差为O(N)
2. 使用注意:
    1. 取得排行榜的时候应该注意限制长度
        - ZREMRANGEBYRANK rank 10000 -1 , 只保留前10000名
    2. SortedSet应该注重于`Score设计`, 
## 二. SortedSet的操作 (复杂度基本都是`logN`)
1. `ZADD rank 100 player1`, 添加一个玩家, Set名 分数 元素名
2. `ZREVRANGE rank 0 9 WITHSOCRES`, 取得前十名
    - REV表示反向
3. `ZREVRANK rank player1`, 查找一个玩家的排名
4. `ZINCRBY rank 50 player1`, 增长一个分数
3. `ZRANGE`, 注意不要指定过大的范围
5. `ZREM`,找到之前的一个值
