# Spring Cache
- 无需修改 JPA 代码, 直接在JPA方法上加伤注解即可使用Redis
1. 优势
    - 在 JPA 数据访问方法上添加 Spring Cache 注解，实现「查询缓存、更新 / 删除失效」
    - 利用 Spring Cache 的 SpEL 表达式，动态拼接缓存 key，适配 JPA 的查询场景
    - 结合 JPA 的事务特性，保证缓存与数据库的数据一致性
2. 使用限制
    1. SpringCache 对`列表、分页、Feed 流`不友好
        1. 只能用统一的过期时间
            - 不能处理: 用户 1 小时，帖子 5 分钟
        2. 不能 缓存预热、主动刷新
        3. 不能配置 分布式锁防止缓存击穿
            - 高并发下容易缓存脏数据,数据不一致,雪崩
        4. 只能存String
            - 自定义序列化（存 JSON、存 Hash、存 List）
        5. 不能 缓存空值、布隆过滤、降级策略
        2. SpringCache 是按 key 缓存，你新增一条评论，怎么让整个列表缓存失效？
        3. SpringCache 是黑盒, 不知道缓存了什么,为什么每名中
    2. SpringCache适合做
        1. 用户详情
        2. 帖子详情
        3. 配置信息
    3. 复杂业务需要手写
        1. 首页流
        2. 评论列表
        3. 点赞、关注、计数
        4. 消息通知
2. 使用
    1. 引入依赖
    2. 配置reids
        ```yml
        spring:
            cache:
                redis:
                time-to-live: 3600000 # 缓存过期时间 1 小时（单位：毫秒）
                key-prefix: "jpa_cache:" # 缓存 key 前缀，避免冲突
                use-key-prefix: true
            redis:
                host: localhost
                port: 6379
        ```
    2. 在 Spring Boot 启动类上添加 `@EnableCaching` 注解，开启缓存功能
    3. 在 Repository 方法上添加 Cache 注解，实现缓存逻辑
        1. 查询
            1. @Cacheable	方法执行前先查缓存，命中则返回缓存值；未命中则执行方法并将结果存入缓存
        2. 确保缓存一致性
            1. @CachePut	执行方法后，将结果更新到缓存（用于新增 / 更新操作）
            2. @CacheEvict	执行方法后，清除指定缓存（用于删除操作）
```java
@Repository
public interface UserRepository extends JpaRepository<User, Long> {

    // 1. 查询单个用户：缓存命中则直接返回，未命中则查询数据库并缓存
    // key：缓存键，这里用用户 ID；value：缓存名称（可自定义）
    @Cacheable(value = "userCache", key = "#id")
    Optional<User> findById(Long id);

    // 2. 新增/更新用户：更新缓存（保证缓存与数据库一致）
    @CachePut(value = "userCache", key = "#user.id")
    <S extends User> S save(S user);

    // 3. 删除用户：清除对应缓存
    @CacheEvict(value = "userCache", key = "#id")
    void deleteById(Long id);

    // 4. 批量删除：清除整个 userCache 缓存
    @CacheEvict(value = "userCache", allEntries = true)
    void deleteAll();

    // 5. 复杂查询：用 SpEL 拼接动态 key
    @Cacheable(value = "userCache", key = "#username + '_' + #email")
    Optional<User> findByUsernameAndEmail(String username, String email);

    // 分页查询缓存：key 包含页码和每页条数
    @Cacheable(value = "userCache", key = "#pageable.pageNumber + '_' + #pageable.pageSize")
    Page<User> findAll(Pageable pageable);

    // 处理空值：避免缓存穿透（查询不存在的 ID 时，缓存空值）
    @Cacheable(value = "userCache", key = "#id", unless = "#result == null")
    Optional<User> findById(Long id);
}
```
