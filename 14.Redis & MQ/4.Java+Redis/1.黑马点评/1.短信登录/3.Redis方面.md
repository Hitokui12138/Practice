# Redis
1. 验证码格式(String)
    - opsForString.set()
    - `login:code:{phone}` | `验证码`
    1. String可以直接设置过期时间
        - 过期时间 `2L MINUTES`
2. 将用户保存在Redis中(Hash), 和生成的token一起
    - opsForHash.put(key, map)
    - user对象转Map
    - `login:token:{token}` | `userMap`
    1. HashMap需要先存, 然后手动设置有效时间
        - template.expire()
        - 过期时间 `30L`, Session有效期是30分钟
    2. 更新有效期
        - 只要发送请求, 触发了拦截器, 就可以更新这个token的有效期了
        1. 取得Redis中的Hash
            - map = ops.entries()
        2. map转Bean
        3. 再用一次template.expire()即可刷新
