# 用户校验
1. 用户校验应该放在拦截器里统一去做
2. 另外还需要把用户信息传给Controller(用户信息是有状态的)
    - 总不能把session传到每个Controller里面吧
    - 每一个进入Tomcat的请求都是一个线程, 因此用ThreadLocal确保用户信息互不影响
# 1. 定义拦截器
1. LoginInterceptor implements HandlerInterceptor
2. preHandle
    1. 判断用户是否存在
    2. 保存用户到ThreadLocal
        - 这段逻辑最好单独做一个类, 用静态方法实现
    3. 之后Controller直接从这个类里取得User信息
# 2. 配置拦截器,让其生效
1. MvcConfig implements WebMvcConfigure
2. 实现addInterceptor(), 还要配置`拦截路径`
    ```java
    registry.addInterceptor(new LoginInterceptor()
                    .excluedePathPatterns(
                        "发送验证码, 登录, 注册的不能拦截",
                        "user/login"
                    ))
    ```
