## 哪些地方会用到Redis?
1. 有些图表数据多, 处理起来花时间, 做一个定时异步执行的程序, 然后结果存在Redis里面
2. 自定义注解, 把校验信息存在redis中
    - 重复请求, 如果Redis中存在, 则说明该请求已经处理过了
3. 常用数据, 热点数据, 项目启动时直接加载到Redis中
    - 比如字典表数据
4. 验证码, token 之类的会过期的数据

# Redis
- Remote dictionary server
- 开源的基于内存的数据存储系统, 是NoSQL数据库之一
- 可以用于 数据库, 缓存, MQ 等场景
1. 优势
    1. 性能极高,数据完全存储在内存中,内存的读写速度（纳秒级）比磁盘（毫秒级）快几个数量级
    2. 数据类型丰富, 单键值对最大支持512M大小数据
    3. 支持数据持久化, 主从复制, 哨兵模式等高可用特性
