# 家用路由器
1. 家用路由器往往是多个小机器的组合
    1. 交换机 (局域网互联)
    2. 路由器 (连接互联网)
        3. DHCP 服务器（自动分 IP）
        4. NAT 网关（内网IP与公网IP互转）
    5. 无线 AP（WiFi 发射器）
    6. 光猫 (光电信号转换)
3. 网关和路由器
    - 不是一个东西, 但家用路由器往往具有网关功能
    1. 网关: Gateway 是一个「功能 / 角色」, 表示门卫这个职业
        - 跨网络的出口, 从这个网络 → 去另一个网络
        - 它是逻辑概念，不是具体设备
        - 网关:    192.168.1.1  ← 这是IP地址,它是你的出口
    2. 路由器 Router 是一个「硬件设备」, 表示门卫这个人
        - 路由器 = 能转发数据包、选路的物理机器
        - 天生就具备 “网关” 功能
        - 路由器:  192.168.1.1  ← 这是设备地址, 它是帮你转发的机器
    3. `家用路由器 核心功能`
        1. 开启了 `DHCP`
            - Dynamic Host Configuration Protocol, 动态主机配置协议
            - 手机连上wifi后, 不用你手动填 IP，立刻就能上网，靠的就是 DHCP
        2. 开启了 `NAT`
            - Network Address Translation, 网络地址转换
            - 网络地址转换, 运营商只给你家 1 个公网 IP, 公网 IP 不够用，所以用 内网 IP + NAT 解决
            - NAT实际上是为解决IPv4地址短缺而开发的技术
            1. 优点
                1. 宽带分享
                2. 安全防护: 不暴露C端的ip
        3. 同时充当了你的默认网关
    4. 在公司 / 运营商
        1. 可能是高端路由器当网关
        2. 可能是防火墙当网关
        3. 可能是三层交换机当网关
    5. 路由器的WAN口和LAN口
        1. WAN 口 = 路由器连 “外网 / 宽带” 的口
            - Wide Area Network 广域网
        2. LAN 口 = 路由器连 “你家设备” 的口
            - Local Area Network 局域网
4. 交换机
    1. 只认识 MAC 地址, 不知道 IP、不知道外网
    2. 只在同一个局域网里转发
5. 光猫
    1. 从路由器WAN口出来后, 可能需要先进入光猫, 然后接入光纤
    2. 光猫 = 光信号 ↔ 电信号 互相转换
    3. 路由器、电脑只认识电信号，不认识光。
6. NAS Network Attached Storage（网络附加存储）
    - 这是一个额外设备
    - NAS = 你家里的 “私人云盘服务器”，就是一台 24 小时开机、专门存文件的小电脑，连在你家路由器上。
    1. NAS, 云盘, 移动硬盘的取舍
        - 临时存、偶尔用 → 移动硬盘
        - 怕麻烦、要方便、能接受上传下载 → 云盘
        - 数据多、要隐私、全家共享、想长期玩 → NAS
            - 最主要的作用就是 局域网内多设备共享

## 路由器对数据包处理
1. 数据包从你电脑网卡发出去, 进到路由器的 LAN 口, 里面的交换机根据 MAC 地址，转给路由器
2. 路由器开始处理
    1. 路由器看到mac是自己, 拆掉旧的以太网头
    2. 然后看 IP 头，发现是去外网
    3. 做 NAT 转换
        - 源 IP 从 192.168.1.100 -> 换成 你家的公网 IP
    4. 重新加一个新的以太网头(运营商网关的 MAC)
3. 从路由器 WAN 口 发出, 一路只看 目标 IP 转发, 最终到达 百度服务器网卡
4. 路由器接收到传回来的包
    1. 数据包回到你家 WAN 口
    2. 路由器查 NAT 表, 这个端口是 192.168.1.100 的
        - NAT 表可以记录 `内网 IP: 端口`,`公网 IP: 端口`,`目标 IP`
        - 这样等数据传回来后一下子就能找到电脑
    3. 把公网 IP 换回内网 IP
    4. 发给你的电脑
