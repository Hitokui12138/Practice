# 上网完整流程
1. 设备介绍
    1. 电脑: 网卡, IP, MAC地址
    2. 家用路由器: 既是网关, 也是NAT转发器
    3. 运营商网关: 宽带入口
    4. 百度服务器: 有公网IP, 网卡
2. 在浏览器中输入百度的网址, 通过`DNS解析`可知对方的IP是`180.101.49.11`
    1. 你现有的东西
        1. 你的内网IP: 192.168.1.100
        2. 子网掩码: 255.255.255.0
        3. 网关: 192.168.1.1(路由器)
3. 大致流程
    1. 你的电脑封装数据包
        1. 给四层/七层 封包 (带路由器的Mac)
        2. 电脑判断百度和你不在一个局域网内, 因此必须发给网关
        3. 最后交给网卡, 变成电信号发送出去
    2. 数据包到`家用路由器`
        - 实际上是`交换机 + 路由器 + Wifi发射器`
        1. 交换机只看Mac地址, 同属一个局域网, 因此直接转发给 路由器 
        2. 路由器看到目的MAC是自己, 收下
        3. 做`NAT网络地址转换`, 把内网 IP → 公网 IP
        4. 查路由表, 去公网 → 发给上级运营商网关
        5. 换上新的MAC头(运营商网关的 MAC), 从 WAN 口网卡 发出去
    3. 运营商网络 → 骨干网 → 百度
        1. 数据包 → 运营商路由器 → 省级网关 → 国家级骨干网
        2. 每台路由器只做一件事: 看目的 IP → 决定下一站发给谁
        3. 最终到达 百度服务器的网卡
    4. 百度服务器处理请求
        1. 网卡收到电信号 → 转成二进制
        2. 内部处理, 构造响应数据（网页内容）
        3. 原路返回数据包
    5. 返回数据包到你家路由器
        0. 通过你家的公网IP找到你
        1. 路由器`查 NAT 表`, 知道这个公网端口 → 对应 192.168.1.100
        2. 把公网 IP 换回内网 IP, 转发给你的电脑网卡
        3. 内核 → TCP → Socket → 浏览器
