# 常用命令
## String
1. CURD
    1. SET K V
    - K是区分大小写的, 默认V是String类型, 二进制安全的, 这意味着不能直接使用中文
        1. 如何显示中文
            - 在登录redis-cli时, 加上`--raw`的参数
        2. SETEX K 10 V , 注意顺序
        3. SETNX K V, 仅当K不存在时, 才会设置键值对
    2. GET | DEL | EXIST V
    3. DEL V
    4. FLUSHALL ,删除所有KV
2. 查询所有存在的K
    - KEYS *  , 可以用正则表达式
3. 带有过期时间的键值对
    - 过期后再GET连(nil)都不显示
    1. 显示一个K的过期时间 Time to Live
        - TTL K , 如果是-1,则没有过期时间; -2表示已过期
    2. EXPIRE K 10 , 把过期时间设置为10秒

# List
1. 创建或者添加列表
    1. LPUSH | RPUSH Klist a b c , 从列表左边或者右边添加元素
    2. LPOP | RPOP Klist 2, 删除最左边或者最右边的元素, 可以加上数量
2. 获取列表内容
    - LRANGE Klist 0 -1 , -1表示最后一个元素
    - LLEN Klist, 查看长度
3. 由此可以实现一个简单的先进先出队列
    - LPUSH, 往列表头部添加一个元素
    - RPOP, 从列表尾部删除一个元素
4. LTRIM Klist 1 3, 只保留第2个到第4个之间的元素, 其他删除, 左右都闭

# Set
- Set不能重复嘛且没有顺序
1. 创建Set
    - SADD Kset a b c
    - 如果添加重复元素, 会返回结果0, 添加失败
2. 获取Set元素
    - SMERBERS Kset
3. 判断一个元素是否在集合中
    - SISMERBER Kset d
4. 删除一个元素
    - SREM Kset b
5. 对两个集合进行交集并集运算
    - SINTER, SUNION, SDIFF

# SortedSet 有序集合
1. ZSET

# Hash 一个存放KV对的集合
1. 创建和添加
    - HSET person name laoyang
    - HSET person age 30
2. 获取
    - HGET person name
    - HGETALL person, 键和值都输出
    - HKEYS
    - HLENS, 长度
3. 删除
    - HDEL person age
4. 其他
    - HEXSIT person name
