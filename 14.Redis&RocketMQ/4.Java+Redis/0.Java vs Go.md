## 2. Java
### 2.1 引入依赖
#### 2.1.1 POM文件
1. `spring-boot-starter-data-redis`, 提供Redis客户端和Spring模版, `没有实现连接池`
    1. 引入Redis核心客户端(两种)
        1. `Lettuce`, 最常用
        2. Jedis, 不要用
    2. 提供Spring格式的Redis操作模版
        1. RedisTemplate, 存储过程可能会出问题
        2. `StringRedisTemplate`, 最常用, 要求所有值都是String
    3. 自动装配Redis相关的Bean
        - RedisConnectionFactory
    4. 预留了连接池配置接口, 但是没有实现
2. commons-pool2, 提供池化技术
    1. 如果想让Redis连接池生效
        1. 引入commons-pool2依赖
        2. 配置连接池参数
3. fastjson2, 可选, 提供JSON序列化的依赖
#### 2.1.2 spring-boot-starter-data-redis
1. 提供哪些常用Bean?
    1. 核心 StringRedisTemplate / RedisTemplate
        1. stringRedisTemplate.opsForValue().set(k, v, t, TimeUnit.SECONDS)
        2. opsForHash(), opsForList(), opsForSet(), opsForZSet()
        3. 在工作中一般不会直接操作RedisTemplate, 而是先`封装成工具类`
    2. RedisCacheManager(`重要,能简化上面的操作`)让你用注解而非硬编码操作缓存。
        - 用 @Cacheable 写缓存逻辑，用 RedisCacheManager 配置缓存规则
#### 2.1.3 commons-pool2
1. 配置好之后最好验证一下
    1. 需要使用 LettuceConnectionFactory 来构建连接池
        - lettuceConnectionFactory.getPoolConfig();

### 2.2 Redis配置
#### 2.2.1 通用基础配置
```yaml
spring:
  redis:
    # 基础连接信息（所有客户端通用）
    host: localhost          # Redis服务器地址（默认localhost）
    port: 6379               # Redis端口（默认6379）
    password:                # Redis密码（无密码则留空）
    database: 0              # 使用的Redis数据库索引（默认0，范围0-15）
    timeout: 3000ms          # 连接超时时间（默认无限制，建议配置）
    client-type: lettuce     # 指定Redis客户端类型（lettuce/jedis，默认lettuce）
    # 哨兵模式配置（可选，集群/哨兵 二选一, 用于主从复制 + 哨兵的高可用架构；）
    sentinel:
      master: mymaster       # 哨兵主节点名称
      nodes: 127.0.0.1:26379,127.0.0.1:26380  # 哨兵节点列表
    # 集群模式配置（可选，Redis集群场景用 分布式集群架构；）
    cluster:
      nodes: 127.0.0.1:7000,127.0.0.1:7001    # 集群节点列表
      max-redirects: 3       # 集群最大重定向次数（默认3）
    spring:
  redis:
    # SSL配置（Redis开启SSL加密时用）
    ssl: false               # 是否启用SSL（默认false）
    ssl-protocol: TLSv1.2    # 指定SSL协议版本（可选）
    # 连接工厂自定义配置（极少用，默认自动配置）
    connect-timeout: 5000ms  # 等同于timeout，优先级更高
    read-timeout: 5000ms     # 读取超时（部分客户端生效）
```
#### 2.2.2 Lettuce/pool专属配置
```yaml
spring:
  redis:
    lettuce:
      # 连接池配置（需引入commons-pool2才生效）
      pool:
        max-active: 20        # 池最大连接数（默认8，负数表示无限制）
        max-idle: 10          # 池最大空闲连接数（默认8）
        min-idle: 5          # 池最小空闲连接数（默认0）
        max-wait: 3000ms       # 获取连接的最大等待时间（-1表示无限制）
        time-between-eviction-runs: 30s # 空闲连接清理间隔（默认-1，建议配置）
      # Lettuce特有配置
      shutdown-timeout: 200ms # 客户端关闭超时时间（默认100ms）
      client-name: redis-client # 客户端名称（可选，便于监控）
      # 3. 高级超时配置（细分场景，优先级高于全局timeout）
      config:
        connect-timeout: 5000ms   # 连接建立超时（默认同全局timeout）
        read-timeout: 3000ms      # 数据读取超时（默认同全局timeout）
        write-timeout: 3000ms     # 数据写入超时（默认同全局timeout）
        # 重连策略（核心！解决网络抖动导致的连接断开）
        retry:
          enabled: true           # 启用自动重连（默认true）
          max-attempts: 3         # 最大重连次数（默认3）
          delay: 100ms            # 初始重连延迟（默认100ms）
          max-delay: 1000ms       # 最大重连延迟（默认1s）
          multiplier: 2           # 重连延迟倍数（100ms→200ms→400ms，直到max-delay）
```
