# 主从复制, 读写分离
- Redis读多存少, 多个只读的从节点可以提高Redis的并发能力
1. 需要确保
    1. 不管读取哪个从节点(slave/replica), 读取结果必须一致
        - 主节点(master)数据同步

## 集群结构
1. 在Docker上开启多个Redis节点
    1. 6380, master
    2. 6381, slave
    3. 两者必须处于同一网络中
2. docker启动配置
    1. --net 同一个网络
    2. --protected-mode no, 关闭保护模式（允许从节点连接）
    3. 主节点到此为止
    4. --replicaof redis-master 6379, 从节点指定一个主节点
3. 在主节点, 输入 `info replication`查看主从状态
    - 天然就能实现读写分离, 从节点不允许写入

## 数据同步原理
1. 第一次同步是全量同步
2. 然后分别增量同步
