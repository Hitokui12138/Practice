# 四层模型（TCP/IP）,七层模型（OSI）
- 七层模型：教科书理论模型（完美、完整）
- 四层模型：互联网真实在用的模型（实用、简化）
## 四层结构 
1. 应用层(具体内容)
    1. 应用层(OSI)
        - 给用户 / 程序用的 HTTPS,聊天信息,业务数据
    2. 表示层(OSI)
        - 主要是翻译、加密、压缩, 把数据变成统一格式
        - HTTPS 加密就在这
    3. 会话层(OSI)
        - 建立、管理、断开连接, 用于保持会话    
2. 传输层(协议, 程序) ``
    - TCP、UDP、端口
    4. 传输层(OSI)
        - 找到程序（端口）、保证可靠
        - `交换机`工作在这层
3. 网络层(目标电脑)
    - IP、路由器,找到哪台电脑（IP）
    5. 网络层(OSI)
        - `路由器`工作在这层
4. 网络接口层(链路层 + 物理层)
    - MAC、网卡、交换机、网线、WiFi
    6. 数据链路层(OSI)
        - 设备之间传数据（MAC）
        - MAC 地址, 交换机、网卡
    7. 物理层(OSI)
        - 真正的硬件：电信号、光、无线电
        - 网线、光纤、WiFi 信号

## 第一步: 你的电脑封装数据包
- 你的电脑判断: 百度不在同一个局域网 → 必须发给网关（路由器）
1. 流程 (每一层都在前面加一个头)
    1. 应用层: 构建HTTP请求
    2. 传输层: `加TCP头`(端口号)
        1. 源端口：比如 50001
        2. 目标端口：80（HTTP）
        3. 还有序号、确认号、窗口大小…
    3. 网络层: `加IP头` 
        1. 源 IP：192.168.1.100
        2. 目标 IP：180.101.49.11
        3. 协议号（6 = TCP）
    4. 链路层: `加MAC头`, 也叫做`以太网头`
        1. 源 MAC：你的网卡地址
        2. 目标 MAC：路由器的 MAC（因为要走网关）
    ```
    [ 以太网头 ]  [ IP 头 ]  [ TCP 头 ]  hello
    ```
    - 这样一个结构叫做`帧`
2. 子网掩码 判断是否在同一个局域网
    - 「目标 IP」和「我的 IP」按子网掩码 “按位与” 后，结果一样不一样
    1. 现有信息
        1. 你的 IP：`192.168.1.100`
        2. 子网掩码：`255.255.255.0`
        3. 网关：192.168.1.1
        4. 百度: `180.101.49.11`
    2. 什么是子网掩码 255.255.255.0？
        - 255 = 这一段我要保留
        - 0 = 这一段我不管
        - 所以这个子网掩码就是`只看前 3 段，第 4 段是主机，不参与判断`
    3. 具体计算
        1. 你的IP按位与运算: `192.168.1.0`, 这个也称为`网段`
        2. 百度的IP按位运算: `180.101.49.0`
        3. 因为二者不同, 因此发给路由器
        4. 如果在同一个局域网, 则不经由网关,直接发 ARP 找对方 MAC
