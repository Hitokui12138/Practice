# 
- 现在信息服务已经建好了
- 接下来考虑让用户服务(java)调用信息服务(python)
- 但是Java调用thrif必须要有Java的API
- 因此现在生成Java版本
# 1. 开发用户服务连接信息服务的接口
- message-thrift-service-api
1. 修改bash脚本
    ```bash
    #!/usr/bin/env bash
    thrift --gen py -out ../ message.thrift

    thrift --gen java -out ../../message-thrift-service-api/src/main/java message.thrift
    ```
2. 执行脚本生成java的message.thrift的API类
3. 在pom中引入需thrift的jar包

# 2. 开发用户服务API
- 建一个新的模块user-thrift-service-api
1. 设计对外的接口
    1. 需要提供能访问数据库的接口
        - 数据结构要在thrift里面实现?
    2. 创建thrift文件
        ```java
        namespace java com.imooc.thrift.user

        struct UserInfo{
            1:i32 id,
            2:string userName,
            3:string password,
            4:string realName,
            5:string mobile,
            6:string email
        }

        service UserService{
            //登录用
            UserInfo getUserById(1:i32 id);
            UserInfo getUserByName(1:string userName);

            //注册用
            void registryUser(1:UserInfo userInfo);
        }
        ```
    3. 生成代码
        ```bash
        #!/usr/bin/env bash
        thrift --gen java -out ../src/main/java user_service.thrift
        ```
# 3. 现在定义该api的实现
    1. 创建新的模块user-thrift-service
    2. 为了找到api模块, 应该在pom中引入
        ```pom
        <!-- 引入接口模块 -->
        <dependency>
            <groupId>com.imooc</groupId>
            <artifactId>user-thrift-service-api</artifactId>
            <version>1.0-SNAPSHOT</version>
            <scope>compile</scope>
        </dependency>
        ```
    3. 创建类impl接口, 实现接口方法
