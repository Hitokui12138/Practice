# Docker实现Redis
1. 创建一个文件夹, 执行脚本
    - cd /Users/peihanggu/GithubLocal/PracticeProject/IdeaProjects/DockerApp/redis
        - start.sh

2. 检查一下3306端口是否被占用
- netstat -an | grep 6380
- brew services list
- -v `pwd`/data:/data , 将数据持久化到本地
- -v `pwd`/redis.conf:/etc/redis/redis_default.conf, 用自定义配置文件覆盖默认配置文件
- hub.c.163.com/public/redis:2.84 , 这个镜像来自163数据中心
```bash
docker stop redis
docker rm redis
docker run -idt -p 6380:6379 \
-v `pwd`/data:/data \
--name redis \
-v `pwd`/redis.conf:/etc/redis/redis_default.conf \
redis:8.2.3
```

3. 连接redis
    - redis-cli -h localhost -p 6380
4. redis get
