# Dubbo
- Alibab开源的
- 基于Java的开源RPC框架 RPC（Remote Procedure Call，远程过程调用）技术, 它让你像调用本地方法一样调用远程服务器上的函数。
- 自动处理所有通信细节
- 你已经在使用 Thrift，如果 Thrift 能满足需求（简单的 RPC），可以继续使用。但如果需要服务发现、负载均衡、监控等高级功能，可以考虑迁移到 Dubbo 或补充这些组件。

# RPC 与 HTTP
1. RPC
    1. 调用方式不同,像本地方法调用
    2. 协议不同: 二进制协议（Thrift/gRPC）或自定义
    3. 性能 更高（二进制、连接复用）
    4. 不能跨语言 ,需要代码生成
2. HTTP
    1. HTTP 请求
    2. HTTP协议
    3. 跨语言 天然支持(HTTP 是标准)

# QuickStart(Spring版本)
1. 建立项目
2. 增加Maven依赖
3. 定义服务接口
    1. 接口模块
        - 提供接口
    2. 服务提供者模块
        1. 实现接口
        2. 需要一个配置文件来配置Dubbo
            - 使用dubbo:service来定义一个服务
        3. 需要一个启动类
        4. 可能遇到的问题
            1. dubbo:registry 是一个广播形式的, 直接使用可能遇到问题
                - 可能需要在启动配置中添加`-Djava.net.preferIPv4Stack=true`
                - 尽量使用IPv4, 客户端也需要这个
            2. Dubbo还支持其他注册方式, 广播方式仅用于本地
    3. 服务消费者模块
        1. 也需要一个配置文件
            - 使用dubbo:reference来引用一个服务
        2. maven
        3. 创建启动类
4. 中间的通讯传输, 序列化反序列化都不需要关心
5. registry相关
    1. 现在定义的是一个广播地址muilticast
    2. 可以尝试zookeeper, redis
    3. 还可以直接设置false, 不注册, 只提供端口直连
