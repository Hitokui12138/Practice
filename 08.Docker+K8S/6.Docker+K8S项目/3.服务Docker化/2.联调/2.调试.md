## 容器组启动后, 可以连接到8080, 但是无法连接8081和8082
- 这是因为8081和8082是内部连接, 不对外开放
1. 如何测试
    - 使用以下命令, 进入网关容器，测试是否能解析服务名并连接
    ```s
    #进入网关容器
    docker exec -it k8s-api-gateway-zuul-1 /bin/bash

    # 测试是否能解析服务名
    ping user-edge-service
    ping course-edge-service

    # 测试是否能访问服务
    curl http://user-edge-service:8082/actuator/health
    curl http://course-edge-service:8081/actuator/health
    curl -v http://user-edge-service:8082/actuator/health
    curl -v http://course-edge-service:8081/actuator/health
    ```
2. 如果用不了ping或者curl命令
    1. 下载
        - apt-get update && apt-get install -y curl
    2. 使用
        ```bash
        # 查看容器内的hosts文件
        cat /etc/hosts

        # 查看网络接口
        ip addr show

        # 查看路由表
        ip route show

        # 查看容器内的DNS配置
        cat /etc/resolv.conf
        ```
3. 网关内部连不上courseapp
    ```bash
    root@68c89d9c0a44:/# curl -v http://user-edge-service:8081/actuator/health
    *   Trying 172.18.0.3:8081...
    * connect to 172.18.0.3 port 8081 failed: Connection refused
    * Failed to connect to user-edge-service port 8081 after 1 ms: Connection refused
    * Closing connection 0
    curl: (7) Failed to connect to user-edge-service port 8081 after 1 ms: Connection refused
    ```
    - 这通常意味着 user-edge-service 容器没有在监听 8081 端口
    1. 检查user-edge-service
        - `docker exec user-edge-service-1 ps aux`

# docker logs小技巧
1. 查看port绑定相关log
    - `docker logs k8s-user-edge-service-1 | grep -i "port\|listen\|bind\|started"`
2. 给Springboot添加一个测试用的依赖
    ```xml
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-actuator</artifactId>
    </dependency>
    ```
