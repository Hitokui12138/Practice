# Docker容器的通讯
1. 方案
    1. 直接通讯
        - 通过容器的ip和端口进行通讯
        1. 缺点
            - Docker的ip和port不稳定, 每次修改都可能会改变
    2. 端口映射
        - 将容器的端口转换成主机的端口
        - 让依赖它的容器去访问主机的端口
            - 本次mysql,zookeeper等会使用这个
    3. 使用Docker的Link机制
        - Link到容器名后, 直接通过容器名称访问
            - 本次微服务之间会时候用这个

# 建立Link关系, 使用docker-compose
- 也可以直接写命令一个个去link, 这里还是用docker-compose
1. 创建`docker-compose.yml`
    - 默认命名就是这个
2. 使用docker-compose运行, 会默认运行当前目录的docker-compose.yml
    - `docker-compose up -d`
    - up -d表示后台运行
3. 重启服务
    ```docker
    docker-compose down
    docker-compose up -d
    ```
