# user-thrift-service模块化
1. 添加fatjar依赖
2. 尝试打包
3. 修改配置文件
    1. thrift.user.ip, 已经运行在docker里面了
        - 作为一个微服务, 可以通过docker的机制`link的方式`通过名字查询这个微服务
        - 两种接续方式
            1. 微服务与微服务
                - user-thrift-service
            2. 微服务与外围服务
                - mysql(本次开发认为微服务之外的都属于外围服务)
                - redis
        ```
        #thrift.user.ip=127.0.0.1
        thrift.user.ip=user-service

        #spring.redis.host=localhost
        spring.redis.host=${redis.address}
        ```
    2. mysql(外围服务)那个为什么不用名字?
        - 这次考虑db是一个外部服务,而不是docker内部的一个东西
        - 微服务-》外部, 就使用${}
        - 微服务-》微服务, 利用Docker的name查找
4. 重新package
5. 写DockerFile
    ```Dockerfile
    FROM eclipse-temurin:17-jdk-jammy
    MAINTAINER xxx XXX@imooc.com

    # 把jar包copy进去, 改一个简单的名字
    COPY target/user-edge-service-2.7.0.jar /user-edge-service.jar

    # 没有其他需要做的, 直接运行
    # 最好写成数组的形式
    ENTRYPOINT ["java", "-jar", "/user-edge-service.jar"]
    ```
6. 写Build文件
    - 地址下次再改
    ```bash
    #!/usr/bin/env bash
    mvn package

    docker build -t user-edge-service:latest .
    # 容器要通过ip访问本地
    docker run -it --name user-edge-service user-edge-service:latest --redis.address=172.0.0.1
    ```
