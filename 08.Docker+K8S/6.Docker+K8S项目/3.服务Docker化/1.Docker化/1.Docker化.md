# 对 user-thrift-service 进行Docker化
1. 考虑配置文件里面的一些配置如果直接镜像化, 将来修改起来很难
    ```properties
    #spring.datasource.url=jdbc:mysql://localhost:3307/db_user
    # 修改后
    spring.datasource.url=jdbc:mysql://${mysql.address}:3307/db_user
    ```
2. SpringBoot可以把服务构建成一个jar包, 用`java -jar`一个命令就可以运行了
    - 再使用 `--mysql.address`来给上面的配置文件赋值
3. Idea打包:
    1. 右上角Maven按钮
        - 找到user-thrift-service->Lifycycle->package
    2. 但对于这种多个模块的项目, 应该先在root目录下,进行mvn install 操作
    3. 可能需要打成fatjar包
4. 如何把jar包放入docker
    1. 写Dockerfile
        ```Dockerfile
        FROM eclipse-temurin:17-jdk-jammy
        MAINTAINER xxx XXX@imooc.com

        # 把jar包copy进去, 改一个简单的名字
        COPY target/user-thrift-service-2.7.0.jar /user-service.jar

        # 没有其他需要做的, 直接运行
        # 最好写成数组的形式
        ENTRYPOINT ["java", "-jar", "/user-service.jar"]
        ```
    2. 运行
        - `docker build -t user-service:latest .`
        - `docker run -it user-service:latest --mysql.address`
