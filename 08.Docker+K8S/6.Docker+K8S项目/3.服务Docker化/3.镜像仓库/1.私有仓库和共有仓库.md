# 私有仓库和共有仓库
1. 共有仓库 DockerHub
    - hub.docker.com
    1. 国内的镜像仓库
        - 阿里云等等
    2. 向公有云push一个镜像
        1. 先打个tag
            - docker tag redis:v1 imooc/redis:v1
        2. push
            - docker push imooc/redis:v1
2. 私有仓库registry
    1. docker提供一个registry, 使用这个镜像来搭建私有仓库
        - https://hub.docker.com/_/registry
        - 拉取下来运行
    2. 给目标镜像打一个tag
        - docker tag redis:8.2.3 localhost:5001/redis:v1
        - docker push localhost:5001/redis:v1
    3. 缺点
        1. 单点问题, 如果这台服务器出问题了,另一台服务器无法接管镜像仓库
        2. 没有一个UI界面方便控制
3. 私有仓库harbor
    - https://github.com/goharbor/harbor
