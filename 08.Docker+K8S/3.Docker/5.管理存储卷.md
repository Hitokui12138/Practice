# 存储卷
1. 作用
    1. 容器中的数据重启后就消失了,因此需要用存储卷来管理数据
2. 概念
    1. volume, 用户只要知道卷名即可
        - 用volume映射容器内的数据
    2. hostPath, 用于映射
## volume
```bash
docker volume ls

# 创建
docker volume create html
# 查看挂载点等信息
docker volume inspect html
# "Mountpoint": "/var/lib/docker/volumes/html/_data",

# 在运行container的时候加上 -v
docker run --name myweb1 -d -v html:/usr/share/nginx/html -p8080:80 nginx:1.19

curl localhost:8080

# 进挂载点看看
```
2. 这个 Mountpoint 是 Docker 虚拟机内部的路径，在 macOS 上不能直接访问。
    - 不能直接cd进入/var/lib/docker/volumes/html/_data
