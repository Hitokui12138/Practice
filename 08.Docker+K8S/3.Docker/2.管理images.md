# 安装Docker
- `brew install --cask docker`
-  docker version,如果只显示Client,说明服务端没有启动
    - `open /Applications/Docker.app`
# Docker结构
1. 使用Client-Server架构模式
    1. 在客户端运行命令
    2. 使用RESTful或者Socket与服务端的docker deamon(守护进程)交互
        - docker deamon管理服务端的各种资源
    3. docker deamon将结果传给客户端
2. 镜像仓库地址 registry mirrors
    - hub.docker.com
    - reg-mirror.qiniu.com
        - 在deamon里面配置
3. 配置文件地址
    - docker info
    - ~/.docker/config.json
    - ~/.docker/deamon.json
    - 配置完成后别忘了刷新和docker重启

# 三种运行镜像的方法
## 1. 拉取镜像
1. `docker pull nginx:1.19`
2. 查看本地镜像
    - `docker images`
3. 运行
    - `docker run -d -p 8080:80 nginx:1.19`
    - -d 后台运行
    - -p 映射端口号
4. 查看`正在运行`的镜像
    - docker ps -a
5. 查看本机ip
    - ifconfig
        - en0 后面 inet 192.168.210.140 就是本机ip
    - 192.168.210.140:8080 看看运行效果
## 2.本地创建DockerFile来运行
6. 替换nginx首页
    1. 查找nginx首页index文件的位置
        1. `docker ps` 看看containerId
        2. `docker exec -it containerId bash`
            - 这样就进入到容器内部了
        3. (现在是在容器内部)nginx一般在 /usr/share/nginx/html里面
        4. 退出容器 exit
    2. 创建`Dockerfile`,修改参数
    3. `docker build -t hello_docker:v1 /Users/peihanggu/GithubLocal/Practice/8.Docker+K8S/3.Docker/HelloDocker`
        - -t 指定镜像名和版本
    4. 运行`docker run -d -p 8081:80 hello_docker:v1`
## 3. 直接修改正在运行的容器
1. 进入容器内部`docker exec -it containerId bash`
2. 修改`echo Hello World! > index.html`
3. 退出容器
    - 这样的话容器就被修改了, 并且会影响正在运行的效果
4. 如果效果可以, 把当前运行的容器创建成一个新镜像
    - `docker commit containerId hello_docker:v2`
    - docker images 
5. 删掉不需要的镜像
    -  `docker rmi hello_docker:v1`
6. 如果正在使用
    1. `docker stop containerId && docker rm containerId`
        - 停掉的同时还要删掉
        - 然后再rmi

# 容器化
1. 流程
    1. 在项目的根目录下,创建一个`Dockerfile`,文本文件
        1. 指定了各种依赖,运行环境,配置等等所有内容
    2. 使用Dockerfile创建镜像
    3. 使用镜像创建和运行容器
2. 查看HelloDocker文件夹
    1. 将这些步骤写入Dockerfile
        1. 安装操作系统
        2. 安装JS运行环境NodeJS
        3. 复制应用程序,依赖包,配置文件
        4. 执行启动命令运行程序
    2. 镜像是按层次结构构件的
        1. 指定一个基础镜像
            1. FROM alpine,指定为linux,alpine是一个linux的发行版,非常小只有几十M
            2. FROM node:14-alpine, nodejs v14是基于linux的,可以直接用
        2. 使用COPY命令复制文件
            1. COPY index.js /index.js
                - 将这个文件copy到根目录下
        3. 在镜像中运行程序,CMD
            1. CMD [ "node", "/index.js" ]
                - 第一个参数是应用程序,第二个是参数
                - node index.js
            2. 也可以直接 CMD node /index.js
    3. 使用Docker创建容器
        1. build -t hello-docker . 
            - .表示当前目录(Dockerfile所在)
        2. 使用docker image ls,查看生成的镜像
            - docker images
        3. 运行
            - docker run hello-docker
    4. 接下来
        1. 已经可以移动到其他环境了
        2. 也可以上传到DockerHub或者Harbor
            - docker pull XXX/hello-docker
        3. 在网站上运行镜像?
            1. https://labs.play-with-docker.com/
                - 给你分配4个小时的虚拟机环境
3. 桌面APP
    1. Volumes 逻辑卷
        - Docker中用来存储数据的,由于容器中的数据不是持久化的
        - 使用逻辑卷把容器中的目录映射到宿主机上,这样就可以把数据保存在宿主机上,从而实现持久化
    2. Dev Enviroments
        1. 可以创建一个开发环境,配置
        2. 把这个环境分享给其他人,避免环境不一致问题
    3. 其他一些拓展
4. Docker Compose
    1. 用于定义和运行多个容器的工具
        - 使用YAML配置,docker-compose.yml
    2. 前段后段数据库缓存负载均衡
        1. 这些服务之间的配合和关联关系就是Compose解决的问题
        2. 比如新同事直接使用docker compose up就可以自动配置各种配置依赖了
